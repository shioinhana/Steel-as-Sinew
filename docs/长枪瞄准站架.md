# 长枪瞄准站架

0.6.2 让长枪的下肢随瞄准俯仰沉降：枪口压低时骨盆下沉、膝盖折叠，枪口抬高或平举时回到原站架。此前站架与瞄准角完全无关，大幅俯瞄时身体仍直立，枪尖看起来是"手臂在够"，而不是整个人在压枪。

## 解算

`SpearMotion.aimCrouchCm(pitch, maximum)` 把俯仰角映射为下沉量：

```text
n      = clamp(pitch / 45, -1, 1)
crouch = maximum · sign(n) · |n|^1.5
```

指数 1.5 使小角度几乎不动，接近 45° 才明显下沉，超过 ±45° 饱和，避免极端俯仰把腿折断。`maximum` 来自客户端选项 `spearAimCrouchCm`（默认 6 cm，范围 0–12，设为 0 即关闭）。

`Locomotion.supported(..., crouchCm)` 只降低骨盆：`drop = max(floor, drop + crouch)`。双脚保持原位着地，膝角由髋到脚的距离自然得出；`floor` 是腿伸直的下限，所以上抬不会让脚离地。旧的 12 参数重载等价于 `crouchCm = 0`。

## 验证

`SpearStanceTest`（`gradlew spearStanceTest`，已并入 `check`）：

- 下沉量随俯仰单调，±45° 内严格递增，之外保持饱和；
- 俯瞄时膝盖弯曲量大于平举；
- 脚底高度始终等于地面（24 px）。
