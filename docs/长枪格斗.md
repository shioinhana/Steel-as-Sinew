# 长枪格斗

原版 1.21.11 所有 `minecraft:spears` 主手物品进入独立长枪类别。持枪按 R 进入格斗模式。

| 输入 | 动作 | 当前基础参数 |
|---|---|---|
| 左键 | 双手向前戳刺 | 3 格，6 点基础伤害 |
| 右键按住 | 双手横杆格挡，右腿后撑、左腿前曲 | 持续挡住正面可格挡伤害；松开即解除 |
| C + 左键 | 左手松枪、右手伸展远戳，侧身右腿承重 | 4.5 格，8 点基础伤害 |
| C + 右键 | 双手横杆撞击，前踏 0.4 格 | 2.5 格，2 点基础伤害；目标击退 2 格 |
| Shift | 右手持枪闪身后跳 | 1 格 / 0.2 秒，不取 WASD 方向；间隔 0.4 秒 |

四种攻击片共用 0.4 秒节奏，0.18 秒接触。距离、基础伤害和后跳间隔属于首次接入的默认调校，可继续按实机反馈调整。

普通左键戳刺的伤害乘数为 `1 + 0.15 × max(0, 接近目标的相对速度[格/秒])`。使用服务器已知运动向量，沿玩家至目标方向投影；横移和远离目标不增加伤害。伤害在命中时结算，接触拍结束后（包括刺空）将鞘翅速度减半并停止疾跑，骑乘时不施加这些减速。普通戳刺之外的远戳和横杆击退不带速度增伤。

默认右手握后段，枪略放身后；持续疾跑满 1 秒，右手改握中段背枪。双手动作按枪杆位置逐帧解算肩肘，左手握中段；远戳释放左手。第一、第三人称分别烘焙，远戳和格挡保留腿部支撑姿势。原版长枪材质沿枪轴归一化挂到实际握点，左右手不重复渲染枪。

击退和前踏使用逐 tick 碰撞移动；墙体会缩短实际距离。服务器射线从玩家眼部起算，并检查墙体遮挡。第一人称本地预测与服务端前踏、后跳匹配。

验证：资源烘焙、握杆接触与伸臂轨迹检查、完整服务端 GameTest。模型投影检查不能代替 dsh 2 实机视觉验收。
