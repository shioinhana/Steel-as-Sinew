# 0.10.1：越肩准星与原版攻击、挖掘对齐

Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21，网络协议仍为 12。

普通物品通过 R 进入越肩观察后，准星以前从偏移后的镜头看向目标，原版拾取却仍从人物眼睛沿朝向发射射线，因此可能选中、攻击或挖掘旁边的对象。现在方块高亮与左键使用同一准星目标，镜头返回第一人称的过渡也覆盖在内。

选取依据实际渲染帧的视图与投影矩阵，包含原版行走晃动、受击倾斜和画面效果。镜头距离只影响找目标所需的射线长度，接受操作的距离仍从玩家眼睛计算，使用原版方块、实体触及属性和物品攻击范围组件。

每次点击与持续挖掘都重新检查眼睛到目标之间的方块及更近的可拾取实体。若有遮挡，准星变红、操作被拒绝，并限频显示“视线被挡住，无法触及准星目标”。不会改打或挖掉遮挡物；已经开始的挖掘通过原版 `stopDestroyBlock()` 中止，清除进度与裂纹。超距同样拒绝并提示。

通过校验后继续执行 Minecraft 自己的 `startAttack()`、`continueAttack()` 及其原版事件、进度、数据包和服务端检查；不新增攻击或破坏协议，不直接修改世界或结算伤害。右键与中键仍使用原版拾取。完整返回第一人称后恢复原版射线，FSRPG 拔刀连招和技能继续走已有战斗流程。

原版带 `PIERCING_WEAPON` 的方向性刺击由服务器沿头部方向处理，不消费客户端 `hitResult`。这种特殊物品保留原版射线和 STAB 流程，将准星投影到原版实际命中位置，不通过额外转向或移动包伪造目标。

本版无配置迁移。发行前运行完整构建、独立投影测试和 DISPLAY5 上的复制世界实机验证。实机仅通过真实按键映射发起操作，记录原版方法入口、发出的原版数据包、实际方块高亮和服务端结果；证据位于 `verification/shoulder-interaction-20261024/`。
