# 0.8.3：双刀手位与近战相杀

双刀默认操作不再允许无限同向连砍。两手先后完成左斩后，继续左键被拒绝；完整自然收招回到默认位置，或反向挥斩实际改变手位后，才恢复相应方向。拒绝发生在扣费、消费反击机会和写入缓存之前。合法相杀结束并回到 READY 时，内部手位与默认姿势同步归中，允许立即使用优势反击；旧攻击记录、普通格挡开关和受击打断不能清洗新刀的手位。

玩家对玩家、玩家对怪物的近战按真实接触时间判相杀，默认相差不超过 **2 tick（0.1 秒）**，包含第 2 tick。双方已经发出的攻击在互达后比较完整护甲前伤害：差值不超过 **3 点**则双方普通格挡、零伤害；超过则优势方只落实差值减 3，并获得一次完美格挡，劣势方进入弹反僵直。10 对 6 仅产生 1 点护甲前余伤。护甲随后正常结算，不重复添加武器、修行或反击倍率，不追加处决伤害。

反击沿用 4 tick 内左键起手、伤害乘 1.5。弓近战撞击也在接受时消费并锁定倍率；怪物在窗口内开始新攻击后，完整前摇结束仍保留锁定倍率。原版怪物没有素材配置时也使用独立接触记录，原生虚方法只执行一次，保留原伤害和命中效果，不伪造动作素材或金闪。

普通单向命中保持原接触时点；已接触的攻击立即记录全额费用，短有效帧不会误退空挥体力。后按 C、闪避或充能不会倒挡旧接触。弓箭飞行判定、原有 C 精准格挡、攻击素材与网络协议 10 保留。

新增可选 `combat.json` 字段 `weaponClash`，默认 `contactWindowTicks=2`、`damageTolerance=3`。已有自定义文件省略整个对象时直接使用默认值，无需重写；严格字段、有限值与边界均校验。具体规则见 [近战相杀](近战相杀-0.8.3.md)。
