# 第三人称上下半身分开制作约定

运行时两层同时播：

| 层 | 控制器 | 负责 | 美术怎么交 |
| --- | --- | --- | --- |
| 下半身 / 位移 | locomotion | idle、走、跑、蹲、跳、落、拔刀、收刀、闪避、全身受击 | **必须带动腿和髋** |
| 上半身 | action | 挥砍、格挡、蓄力、格挡结束 | **不要带动腿** |

攻击时下半身继续走/跑，上半身播砍。两套可以分开做、分开改。

## 骨骼

第三人称 `player_longsword` / `player_doublesword`：

**下半身（只放在走跑跳闪避里）**

- `root`
- `lower_body`
- `leg_l` `leg_r`
- `lower_leg_l` `lower_leg_r`
- 若有：`foot_l` `foot_r`

**上半身（只放在砍、格挡、蓄力里）**

- `upper_body`
- `head`
- `upper_arm_l` `upper_arm_r`
- `forearm_l` `forearm_r`
- `hand_l` `hand_r`
- `hand_item_l` `hand_item_r`（有则写）

腰扭放在 `upper_body`，不要扭 `root` / `lower_body`，否则会盖掉走路。

## 片名

| 用途 | 交的片 | 程序用的片 |
| --- | --- | --- |
| 四向挥砍、双刀劈 | `attack1`… 全身或上半身均可 | 构建时生成 `attack1_upper`（去腿） |
| 走跑 | `walk_hold` `run_hold` 等 | 原名 |
| 格挡 | `defend` | `defend_upper` |
| 闪避 | 将来 `dodge_*` | 全身，走 locomotion |

现在没有独立闪避片，闪避仍复用 `run_start`（全身）。

## 导出

- 攻击、格挡：`loop: false`；格挡持有可用 `hold_on_last_frame`
- 走跑待机：`loop: true`
- 不要改骨骼层级和名字
- 出刀帧单独标时间，给判定用
