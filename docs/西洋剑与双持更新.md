# 西洋剑与双持更新

## 本次行为

- 主手持剑、另一手不持剑时，R 拔刀进入西洋剑模式；双手持剑仍为双持模式。仅副手持剑不能拔刀。
- 西洋剑左键按下发起攻击，服务端在四个指定攻击片中随机选择，所有普通攻击伤害为 6，不再检查左右手连招位置。
- 右手持剑、身体侧向、头部朝前；已修正旧单手骨架的左右镜像错误，同时修正第一人称主手挂点。
- 西洋剑命中采用准星射线，最远 3 格，单个可见目标；不能隔墙、不能靠扇形擦中。
- 右键按下立即请求刺击，服务端收到请求即结算，伤害 9；普通刺击全长 0.50 秒，强化刺击（蓄力破甲命中）全长 0.20 秒，接触判定与位移都落在片长的一半（0.25 秒 / 0.10 秒）。命中无动作锁定，落空恢复 20 tick（1 秒）。刺击无论结果均冷却 40 tick（2 秒）。收刀和换武器不能清空冷却或恢复。
- Shift：单手短闪身 2 格；双持不播固定闪避片，改为 0.2 秒内提高移动速度上限（`MOVEMENT_SPEED` +300% = 普通 4 倍，冲刺时 5.2 倍；属性带来的视野变化已由 `ComputeFovModifierEvent` 抵消，只改移速），移动中按下自然形成一次突进（0.2 秒约 2.7 格，冲刺约 3.5 格），可衔接跳跃、挥砍或格挡。C：蹲伏。X：格挡。
- 收刀（R 再次按下）：西洋剑为挽剑花收刀，全长 1.65 秒。剑在胸前快速来回转动约 4.2 圈（6 次变向），收势后右手横过身体把剑推向腰部左侧的假想剑鞘，左手同时扶住鞘口；第一人称同节奏，剑尖在画面内画出约 0.7 格的圆，最后停在画面左下方。单手/太刀/双持各自的收刀片与时长不变（太刀 0.7333 秒自带收刀片）。
- 锁敌 HUD：锁定敌人头顶依次显示 名字 / 生命值（整数，非整数保留一位）/ 本次西洋剑连击数 `n/4`；第 4 刀剥夺 AI 后，这一行改为显示剩余剥夺秒数（如 `0.8s`），每 0.1 秒刷新一次。全部使用原版字体，与名字同一套排版。攻击次数一行按能否打到变色：敌人在可攻击范围（4 格内且有视线）时绿色 `0xFF55FF55`，超出范围时黄色 `0xFFFFD24A`，判定与刷新同为 0.1 秒一次。
- 刺击位移：右键刺出时角色自动向前移动 0.5 格（在接触判定那一拍开始，分 3 tick 完成），**只前进不后退**，取消原来的半格回撤；刺完停在原地，是否走位由玩家自己控制。
- 单手西洋剑连击门：第 1/2/3/4 刀之后分别等 0.4 / 0.4 / 0.4 / 0.5 秒（8/8/8/10 tick）。强化刺击命中后 3 秒内整套门收紧为 0.3 / 0.3 / 0.3 / 0.3 秒（6/6/6/6 tick），窗口到期或未命中则回到普通门。
- 第四刀的命中判定比前三刀晚 0.05 秒（1 tick）结算，其余片保持 0.18 秒接触帧，所以第四刀挥到后半段才判定。
- 强化刺击和闪避拥有最高打断优先级：二者都能直接打断正在进行的攻击、格挡、闪避或收招，只受各自冷却限制（强化刺击仍受自身 2 秒冷却）；普通刺击仍要等当前动作到取消帧。
- 双刀连击门：基础间隔 0.45 秒（9 tick）。同一只手连挥两刀后的第三刀变 0.6 秒（12 tick）；另一只手挥砍会把这一手的连挥计数清零，所以「左左右右」循环永远不会被减速，鼓励双手交替出刀。
- 双刀动画末尾帧延长 0.1 秒：片长仍是 0.4 秒，播完后把最后一帧定格 0.1 秒，避免两次连击之间闪回待机姿势造成的闪烁抽搐。**后摇打断窗口不变**，仍是连击门本身（`DUAL_INTERVAL_TICKS`，现 0.45 秒）。
- 双刀连击不再错位：`retarget_attack_playback.mjs` 现在把双刀五段攻击（`attack_1/2/3/4` 与 `attack_dual`，含 `_upper` 变体）的首帧与末帧统一收到待机站姿上（原先每段各回自己的起手姿势，段间跳变 70–135°）。`tools/check_combo_boundaries.mjs` 守住「每段首尾都落在待机站姿」这条不变量，已挂进 `processResources`。
- 连击/格挡后左右手不再播错：客户端三处镜像修补——① 服务端每次成功挥砍回传的 `(方向, 手)` 现在被客户端采纳，单次不同步不会滚成整段连击用错手；② 服务端确认到达时，如果本地正在播的正是同一段动作（或确认属于更早的旧动作），不再重放该片（原来会从服务端那一段重新起播，画面就是抽搐/错位）；③ 格挡开始、蓄力挥砍、闲置超时都按服务端 `resetHandsApart()` 一起重置左右手与西洋剑连段序号，闲置计时改为从片尾（而非后摇窗口结束）起算。
- 客户端不再把服务端回传的攻击间隔夹到太刀范围（5–9 tick）：双刀同手第三刀 12 tick、西洋剑第四刀 10 tick 都会被截短成 9，导致客户端提前发招、被服务端拒绝、预测队列错位——这正是连击后错误播放的根源。
- 双刀自动格挡：每次出手后的 0.1 秒视为举防，这期间挡下攻击即武装双劈，下一次攻击自动释放双劈——触发条件统一为「格挡后攻击」，不再要求左右键同按。完美格挡与持续格挡减伤同样会武装双劈。
- 每次确认接触都会自行开一次伤害窗口：原版 10 tick 受击冷却会吞掉等额伤害的第二击，而双刀 9 tick、西洋剑 8/10 tick 的节奏都在窗口内，之前每隔一击就完全没有伤害。
- 拔刀模式下镜头视野恒定：攻击命中的 FOV 冲击已删除，冲刺/加速移动也不再拉远或加宽视野（`MOVEMENT_SPEED` 带来的视野变化在 `ComputeFovModifierEvent` 里直接中和，相机架位也不再因奔跑变远）。检视仍会轻微推近，但不改视野。
- 双持格挡期间新开始冲刺（默认 Ctrl+W），在 2 格范围内产生一次击退，不附加伤害；同一次举防只触发一次。
- 成功格挡窗口为按下后的 1–6 tick，即 0.05–0.30 秒（含边界）；第 0 tick 不算成功格挡。持续格挡后段保留减伤。

距离、伤害与范围为本次采用的默认数值，时间按用户要求实现。
