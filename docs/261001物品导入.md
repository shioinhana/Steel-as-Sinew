# 261001 模型导入（0.5.4）

原始来源为用户提供的 `261001.7z`，解包文件和导入清单保留于 `artwork/imports/261001/`。单体模型导出为 Minecraft 1.21.11 原生物品模型，保留贴图、面 UV、自由 XYZ 旋转和作者的显示变换。

平放的冒险者牌及下界币只调整物品栏显示角度、居中和缩放，使正面完整可见；手持和落地显示保留原设置。

新增物品在创造模式“材料”页和物品搜索中可获得，也可使用 `/give @s fsrpg:<物品 ID>`。

| ID | 名称 |
| --- | --- |
| `money_pouch` | 钱袋 |
| `gold_coin` | 金币 |
| `silver_coin` | 银币 |
| `crystal_coin` | 晶币 |
| `nether_coin` | 下界币 |
| `gold_adventurer_badge` | 金色冒险者牌 |
| `cobalt_adventurer_badge` | 钴色冒险者牌 |
| `copper_adventurer_badge` | 铜色冒险者牌 |
| `silver_adventurer_badge` | 银色冒险者牌 |

`硬币.bbmodel` 使用金币贴图；银币使用同一钱币几何和包内银色贴图。文件名为 `金币.bbmodel` 的模型使用 `jingbi.png`，接入名称为“晶币”。`综合.bbmodel` 是多物品展示场景，保留为源文件，游戏中使用各个独立物品。

这些是独立物品，交易、牌照升级和钱袋容器功能没有在本次素材导入中定义。物品模型通过游戏官方渲染路径显示；验收截图为实机渲染，开发验收界面不进入发行 JAR。
