# 双刀与长枪 · 0.3.1

适用于 Minecraft 1.21.11 / NeoForge 21.11.45。三种档位共享服务器战斗阶段：前摇可取消，判定阶段普通操作不能取消，但能缓存一招；判定完整结束后跳过后摇衔接。未续招则正常收招。缓存不提前扣资源，重复点击不积累整套自动连招。

## 装备和操作

装备匹配武器后，唯一状态自动拔刀；同一武器配置多个状态时，R 依次切换，V 可选择当前武器匹配的档位。切到普通物品自动收刀。双刀需要主副手各一把配置内的剑；默认支持木、石、铁、金、钻石和下界合金剑。长枪默认支持 1.21.11 的木、石、铜、铁、金、钻石和下界合金长矛。旧预留档位的三叉戟不再用作默认长枪。始终读取实际 ItemStack 的官方模型、显示变换和附魔光效，不制作替代武器网格。

E 格挡，左 Alt 闪避，K 编辑前摇、判定、后摇和技能数值。编辑器初次进入默认选择当前档位的第一招，左右箭头可切换全部技能。西洋剑原有操作保持可用。

## 双刀单次挥砍

左键固定左手左斩，右键固定右手右斩。点按一次一刀，按住不自动挥砍，同侧可以反复点击。方向以角色为准，不随自由镜头的屏幕方向翻转。

| 输入 | 默认出招 | 收招姿态 |
| --- | --- | --- |
| 左键 | 左手左斩 `dual_ll` | 双手低持刀 `dual_idle_00` |
| 右键 | 右手右斩 `dual_rr` | 双手低持刀 `dual_idle_00` |

服务器按输入选择固定的手，不再限制同侧挥砍次数。旧技能 `dual_rl`、`dual_lr` 保留，可通过命令施放，并继续用于已有任务与配置引用；普通左右键不再自动轮到这两招。

同键在前摇再次点击会缓存同一只手的下一刀；另一方向输入按配置取消前摇并切换到对应的手。判定阶段内输入只缓存，不能截断当前有效帧；后摇点击可立即衔接。任意时刻最多保存下一刀，连续点击不会积累整套自动连招。默认每刀 4 / 3 / 7 tick，消耗 12 体力，基础伤害 3.8。左手刀使用副手物品的材质倍率；换掉任一武器会中止正在进行的双刀攻击。

镜头为第三人称背后自由环绕。鼠标只旋转镜头；WASD 按镜头方向移动，非攻击状态下角色朝移动方向转身。静止时首次攻击采用当前镜头方向，移动中攻击沿角色方向。攻击后保持角色方向，镜头仍能环绕；停在原地的后续攻击也沿最后锁定方向，恢复移动后才解除方向锁定并由移动方向带动角色转身。

## 长枪游标与轨迹

侧身面对目标，左手握中段，右手握后端。两手默认相距 58 cm；枪杆方向与手掌对齐。点刺向前送枪，移动时保留下身步态，上身维持两手握持。

拔刀后显示第三人称背后镜头和一个矩形瞄准区。鼠标在区内移动游标，不带动角色转向；到达边界后继续向外移动的部分转为角色与镜头转向。实际操作使用被游戏捕获的鼠标和绘制的游标，不把操作系统鼠标释放到另一块屏幕。

- 点按：松开时向游标所指的位置刺击；两个鼠标键都可使用。
- 按住并拖动：记录游标扫过的方向，松开后执行扫击。默认至少按住 3 tick，轨迹至少移动 5°。
- 短按或拖动幅度不足：仍按点刺处理。
- 打开界面、收刀或失去游戏窗口焦点：放弃未释放的拖动。

点刺默认 5 / 4 / 9 tick，消耗 20 体力、伤害 7、距离 4.5 格；扫击为 6 / 10 / 12 tick，消耗 30、伤害 5.5、距离 4.1 格。游标从实际第三人称相机和动态 FOV 发射射线，先选择沿线物体或方块，再换算成玩家的攻击方向。动画另行补偿眼睛与执枪手的视差。

服务器只接收方向与轨迹，独立检查距离、墙体遮挡、判定阶段、资源、PvP 权限和同次攻击的目标去重。扫击沿记录路径分段检测，不把整个屏幕或整片扇形判作命中。最多 32 个轨迹点、总转角最多 240°；枪尖不能因点击远处目标而超出技能距离。缓存的轨迹仅影响下一招，不会改变当前有效判定。

## 配置与动画

| 文件 | 调整内容 |
| --- | --- |
| `config/fsrpg/skills.json` | 六个新技能的时间、消耗、伤害、距离、动作引用 |
| `config/fsrpg/styles.json` | `controls` 的模式、四个双刀动作 ID、扫击 ID、枪杆判定半径，以及 `cancels` 取消规则 |
| `config/fsrpg/weapons.json` | 主副手武器列表、材质伤害倍率 |
| `config/fsrpg-client.toml` | 矩形大小、拖动阈值、越肩偏移和原有身体表现参数 |
| `config/fsrpg/models/dual_blade.fsvoxel` | 左右单刀、中立低持刀待机、格挡及分层站姿；保留旧交叉斩与手位动作 ID |
| `config/fsrpg/models/spear.fsvoxel` | 双手握枪待机、点刺、扫击、格挡及分层站姿 |

`controls.mode` 为 `dual`、`spear` 或兼容旧连击的 `ordered`。双刀左键使用 `leftHandLeft`，右键使用 `rightHandRight`；`rightHandLeft`、`leftHandRight` 保留旧技能引用兼容。长枪使用 `sweepSkill` 和 `spearRadius`（默认 0.18 格，范围 0.02～0.6）。引用、有限数值和未知字段都会校验。

客户端默认值：`rapierShoulderOffset=0.65` 格，`spearCursorWidth=0.56`、`spearCursorHeight=0.5`（屏幕占比），`spearHoldTicks=3`，`spearDragDegrees=5`。`spearChestReturnDegreesPerSecond=90` 调整枪姿恢复侧身的速度，`spearAimReturnDegreesPerSecond=240` 调整收招后回到游标方向的最大角速度；这些表现参数不改变服务端攻击轨迹。模型是文本格式；`tools/author-weapons.mjs` 经实际 Workbench 命令存储、保存副本和导出，所有运动动作以 60 Hz 保存。`workbench/rapier-workspace/dual_blade-resource.json` 和 `spear-resource.json` 记录可继续打开编辑的副本。

JSON 改后执行 `/fsrpg reload`；动作改后在 K 窗口重载模型。原版资源包若改变长矛的贴图轴向或握持显示变换，需对应调整物品握点校准。

## 0.3.1 动作返修

双刀左右单刀按镜像轨迹制作：较高抬臂蓄势，腰肩带动上臂，小臂逐渐展开，沿较宽的斜下弧挥过目标；支撑手配合回收，余势结束后双手回到中立低持刀姿。枪的回收/送出主要来自手臂相对肩部的运动，腰部作小幅前移与倾身；极端目标方向允许胸部转向以保持双手握持。胸肩呼吸和头部起伏采用连续角色时钟，奔跑使用各档位的上身持械动作。

验证录像增加两武器完整呼吸周期、前后左右移动、奔跑/停止、移动中攻击与斜前无遮挡动作机位；也检查细臂皮肤的实际双手握距与共轴残差。

下一招的同步包若在当前视觉有效段结束前到达，客户端保留最新请求，先走完当前动作的 `active_end`，再接入下一段。无需按特定时机点击；服务端仍负责输入缓存、允许条件和伤害，视觉保护不会延长服务端的有效时间。合法前摇取消与后摇跳过保持。

双刀物品柄心校准到官方剑贴图中的柄中央，采用50°斜握；手腕至指节的长轴继续小臂方向。默认双手低持髋侧，肘在掌后。手腕保持中立，肩与有限的前臂旋前共同转刃，大小臂长度固定；旋前沿前臂表面逐渐分布，避免集中扭转肘部。客户端在前摇前40%以内完成姿态过渡，保留抬臂蓄势，支撑手使用动作自身的编舞。

长枪也使用横握拳心：拳头沿小臂，枪杆沿拳头横轴，两掌保持58cm共杆。闭合IK限制腕部偏折与旋前，极端方向通过必要胸部转动进入肩臂可达范围；胸部倾斜与位置、头部姿态、下身步态仍保留。解算沿用前一帧的胸部与握点姿态，并叠加当前动作变化，避免收招时突然换到另一侧；就绪和收招阶段在可达范围内逐渐恢复侧身。动作时间按连续时钟推进，收招后的枪尖方向先按配置的角速度过渡、再解握点，避免前手随枪突然甩转。攻击判定阶段保留服务端的实际枪尖轨迹。
