## 快跑改为低位后置拖枪

真实地面 sprint 且有实际水平位移时，右手在身体后侧较低处持枪，枪尖指向身后下方，左手释放枪杆，自然弯肘并与双腿反相摆动。普通行走继续双手持枪。身体、头部和脚步使用同一步态时钟，头部不过度随胸扭转；不把跑步做成上身朝前、腿部不跟随的独立转轴。

常规身体局部坐标下，右掌目标约为 **(-44, 24, -32) cm**，并随步态有小幅变化；这里是骨架局部数值，不是玩家传送或世界坐标。枪的实际世界 Y 方向持续向下，位置和方向均以真实官方 ItemStack 挂点、完整枪杆为准。转接先在身前放平，再沿身体外侧转向后下方，避免枪杆横穿身体。

本轮把上臂 **37.5 cm**、前臂 **25 cm** 与手内掌长 **6.25 cm** 分开处理，按真实两段手臂求解肘点，再独立处理腕掌方向；左肘采用正确的自然屈曲方向，避免自由手臂向身体后方折起。右手、手腕与官方武器渲染使用同一条链，不用替代枪网格掩盖握点误差。

进入默认 **14 tick（0.7 秒）**，停止后 **12 tick（0.6 秒）**回到普通双握；回收时持续衔接最新瞄准。实际攻击开始立即清除跑姿权重并恢复双手，不等回收时长结束。完整跑姿权重时继续跳过正常双手 IK，固定预算解析手臂与步态负责这一段显示，不引入昂贵逐帧全局搜索。

极端起始瞄准回双握时仍可能较快：独立 60 Hz 路径的最坏单帧关节转角约 **34.98°**、右掌位移 **20.43 cm**、枪轴转角 **22.67°**。本版已通过完整枪杆 / 握点避碰和常规实机验收，上述数据保留为极端转接的实际限制。

## 在离地基础姿势上增加运动响应

普通跳跃和下落仍从实际离地姿势继续，不因空中状态切成格挡。本轮增加 AirInertia 显示层，输入来自实体**实际模拟位移的速度和加速度**，包含上升、下落及水平运动变化；按模拟时钟观察，渲染时平滑采样，不用反复播放 jump / fall 动画或周期正弦晃动。

默认最大身体俯仰 **3°**、身体侧倾 **1.6°**、腿部俯仰 **4°**、腿部侧倾 **1.5°**。上身、头、双臂和物品作为共同链绕腰口响应，腿绕各自髋部响应，腰部连接与手内握点保持；长枪在必要时进一步缩小装饰性胸部倾角，避免它压过枪杆避碰约束。

空中真实攻击继续播放原有上身动作，下肢保留离地基础姿势，只叠加普通惯性权重的 **25%**。本轮也修复空中主动格挡的腰口：格挡与攻击一样保留起跳下肢，经 AirPoseJoin 把当前上身接回同一骨盆，避免真实按 C 后躯干退回地面姿态而和腿脱离；格挡的惯性权重仍为 **0**。受击、闪避、拔收刀等真实动作同样优先，该层权重为 **0**；落地清零，死亡或显示生命周期变化会清理状态。基础离地姿势与附加惯性分开保存，避免每渲染一帧又把上帧晃动积进下一帧。

这层只改变越肩 / 第三人称人物显示，不修改实体速度、重力、碰撞、跳跃能力、空中攻击判定、伤害或资源。**第一人称本轮未新增专用惯性动作稿**，现有第一人称动作继续保留。

## 客户端配置

config/fsrpg-client.toml 新增显示项：

```toml
airInertiaStrength = 1.0
```

范围 **0–1**、默认 **1**；设为 **0** 则继续精确保持离地基础姿势，不加这层晃动。部署不覆盖已有客户端 TOML，既有显示参数与自定义 JSON 保留。未写新字段时由客户端配置定义使用默认值，不迁移伤害、体力或技能树。

本轮 Shift 仍沿用 0.7.9 的落地新按一次水平冲量与自然物理，空中禁用；Alt 闪避、C 精准格挡和原左键反击规则保留。本轮没有借新版本号激活下述技能提案。
