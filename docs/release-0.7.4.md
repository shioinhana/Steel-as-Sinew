# 0.7.4：等级体力与怪物攻击接触时序

玩家总等级使用原版 `experienceLevel`，与 HUD 的 Lv 一致，不读取武器成长分数。

| 等级 x | 体力上限 | 每秒回复 |
| --- | ---: | ---: |
| 0 | 50 | 5 |
| 1 | 51 | 6 |
| 10 | 63.22 | 10 |
| 100 | 103.63 | 19 |

x≥1 时，上限为 `50 + x^0.8 + 3*ln(x)`，保留小数；回复为 `floor(5 + sqrt(x) + ln(x))`。x=0 单独使用基础 50 / 5，避免 `ln(0)`。实际恢复按服务端每 tick 的 `回复/20` 累加，原有体力回复延迟保留。升级只提高上限及回复速度，不自动补满；降级、死亡重建、持久化恢复和配置重载统一使用派生上限截顶。

基础值继续在 `combat.json.maxStamina` 和 `staminaRegenPerSecond`；新 `staminaLevelScaling` 配置各增长系数。首次升级精确备份原 `combat.json` 到 `stamina-level-backup-v1/combat.json`，只迁移基础 50 / 5 和缺失的等级系数；`stamina-level-migration-v1.json` 阻止重复迁移，之后的自定义调整保留。

18 类生物、19 段近战动作使用服务端 `WINDUP → CONTACT → RECOVERY` 时序。在 `doHurtTarget` 入口先排程，前摇不执行攻击和附魔副作用；接触时重新确认目标、距离、视线和装备，再通过原类的完整虚方法执行一次攻击。普通格挡、完美格挡、敌人 4 tick 僵直和左键反击因此都在真实接触时判定。完美格挡、死亡、目标失效、换武器和配置重载会取消对应待执行攻击；脱离距离或遮挡可令本次攻击挥空。嘎枝冻结、末影人凝视冻结，以及监守者钻地 / 出土 / 切换音爆时，也会取消已排队的近战，保留这些生物原有的行动限制。

服务器发送同一序列的 BEGIN / CONTACT / CANCEL / END，客户端按世界 tick 和渲染 partial tick 播放现有源曲线，接触帧按前后两段时间映射精确落在命中 tick。受控生物不再根据原版挥手动画猜测攻击起点，接触时的原版事件也不会重复启动素材。详细覆盖、源曲线依据和可调参数见 [怪物攻击接触时序](怪物攻击接触时序.md)。

源素材没有作者标记的命中事件，接触点根据现有攻击曲线推断，并写入 `creature_combat.json` 供调整。弓弩射击、法术、爆炸、Boss 特殊攻击及缺少近战素材的实体保留原有行为；本版不为这些路径虚构接触帧。
