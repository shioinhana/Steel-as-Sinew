## 右手腰后持握，枪杆斜跨背部

本轮将右手置于右侧腰后持握，枪杆主要沿背部平面由右下斜跨至左肩上方，枪尖从对侧肩部外伸出，杆尾位于右下。左手离开枪杆，自然弯肘并与步法反相摆动；身体和持枪随真实步态有小幅变化。

用户提出参考《黑神话：悟空》的行走和奔跑。本轮按用户明确的斜背外形与步态要求制作，尚未对该游戏的动作参考帧作精确时序或骨骼对齐，不宣称复刻其原作动作。

实现继续使用真实上臂 **37.5 cm**、前臂 **25 cm** 与掌心偏移 **6.25 cm**，通过两骨 IK 及独立腕部保持实际握持。发布包仍从真实 ItemStack 走官方武器渲染，不换用替代枪网格。全杆避碰沿用现有安全判定，独立检查背面斜跨位置与真实握点；不会为获得斜背外形而允许穿过躯干或头部。

普通行走继续身前双手持枪。仅真实地面快跑且有水平位移时进入背负姿态；停止后回到普通双握并跟随最新瞄准，真实攻击立即恢复双握。默认 **14 tick（0.7 秒）**进入、**12 tick（0.6 秒）**停止回双握。转接依次经过右侧起枪、送至背后，再斜跨背部；收回沿同一受约束路径衔接最新普通双握目标。

独立 stock / slim 骨架验证覆盖 18 个起始瞄准、每起点 240 步转接和 180 帧完整步周期、9 组运动方向，以及 30 / 60 / 120 Hz 起停、快速重启与回收时改瞄准。全部 **421,165 项检查通过**，包括沿用的完整 -60..178 cm 枪杆判定、独立真实胸 / 头盒、13 个渲染腰椎截面和释放后的左上臂 / 前臂盒，以及实际官方 ItemStack 握点与真实骨长。

独立验证的满权重实测：背面仰角 **40.464–42.089°**；杆穿过胸局部 X=0 平面的高度 **66.178–71.337 cm**；右掌胸局部 Z 为 **-39.400 至 -36.600 cm**；最小世界枪轴 Y 分量 **0.56290**，自由左掌至枪杆最小距离 **70.774 cm**。这些是独立骨架测试值；最终客户端的真实满权重极值见下文验收记录。

极端起始瞄准的转接仍可能较快：独立 **60 Hz** 路径最坏单帧关节转角 **38.415°**、右掌位移 **16.501 cm**、枪轴转角 **22.623°**；常规步态与过渡沿用既有速度门禁。最终原生场景的完整枪杆、实际握点与腰口均通过，15 个场景的未编辑原图也已逐一核对。

0.8.0 的空中惯性层保留：普通跳落从离地基础姿势继续，并响应当前上升、下落与运动变化；实际攻击、主动格挡等状态继续优先。此次只调整人物显示，不改变角色物理、服务端命中、伤害、资源、已有技能或输入规则；16 招技能仍为 [0.8.0 设计提案](武器技能设计-0.8.0.md)，未在此版本启用。

## 以真实背面和侧面画面验证

证据目录为 verification/spear-diagonal-20261021/。实机只使用带独立标记的复制世界 **FSRPG Diagonal Spear Review 20261021 01**，测试窗口固定于 Windows `\\.\DISPLAY5`。拍摄用背面、正面和右侧镜头观察实际人物，镜头位置变化不改变玩家移动、碰撞和输入。

满权重跑动须同时满足以下外形条件，测量对象是实际提交的骨架与官方枪杆：

- 胸局部杆轴 X 分量大于 **0.55**、Y 分量大于 **0.5**、前后 Z 分量绝对值小于 **0.15**，背面斜角为 **30–60°**。

- 整杆与胸局部 X=0 平面的交点处于高度 **50–100 cm**、后方 **30 cm** 以外，验证它确实斜跨上背，而非只放在身体一侧。
- 完整枪杆安全检查继续通过，自由左臂与真实双腿持续跑动；停止与攻击恢复双握，跑跳继续通过惯性与腰口验收。
