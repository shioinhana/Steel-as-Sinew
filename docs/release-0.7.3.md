# 0.7.3：长枪、体力消耗、完美格挡与银色冒险者牌

2026-10-16 完成完整构建与同一发行 JAR 的 DISPLAY5 实机验收。六场性能、官方画面设置复核、战斗数值与徽牌显示均通过；下文分别记录测量范围与仍存在的限制。

## 长枪与逐帧开销

实机长枪改为跟踪上一帧的可行握姿：先测试原动作位移、上一实际握点和解析手臂候选，再在固定数量的局部握点与胸向候选中寻找解。局部候选总数与有限目标闭环投影次数均有明确上限。

遇到明显关节跳变时，先在有限枪轴目标对应的后臂几何圆上，解析求取肘角限位与前手可达范围的交集；固定数量的候选覆盖各合法弧的近点、边界与内部。必要时补充有限胸向分支，在同一局部搜索预算内延续，再对实际渲染姿态检查握距、关节角度、完整枪杆避碰和连续性。实机腋下持枪路径不再调用旧完整求解器，最多 192 个局部候选、每个 24 轮闭环投影，以及 97 个解析桥接候选。

每个原生渲染帧继续采样动作；皮肤、盔甲和手持物品共用同一角色本帧的姿态结果。

枪轴仍指向有限动画目标，双手使用当前动态握距，保留关节角度与完整枪杆的胸、头、腰段避碰。运行时记录姿态请求、缓存命中、求解次数与耗时；六场实机中重复求解、旧全局求解回退、枪杆避碰失败与握点失败均为 0。准星投影缓存覆盖全部几何输入，实体拾取改用实际射线的包围盒作粗筛，精确命中规则保留。

`spear_thrust` 完整动作改为前摇 **1 tick**、有效 **1 tick**、后摇 **2 tick**，合计 **4 tick = 0.2 秒**。保留原冷却与后摇取消规则。

最终离线连续性验收的 **5,070 个姿态、136,906 项检查全部通过**；另一个 **2,880 姿态极值采样**的完整枪杆不安全帧与无解帧均为 **0**。动态瞄准的待机 / 点刺 / 扫击单次求解 P99 分别为 **3.42 / 2.99 / 3.08 ms**，这三组的最大值为 **3.90 ms**。这些是离线求解器数据，不能换算为游戏 FPS，也不代替 DISPLAY5 原生客户端验收。记录见 `verification/spear-realtime-20261016/micro/` 的 `underarm-motion-softbudget.json`、`quality-final-soft.json` 与 `final-soft-bounded.json`。

手臂与躯干的接触仍是搜索中的软偏好，不是零穿插的硬保证。720 姿态同轨比较中，点刺、扫击的接触指标改善，但待机及部分短轨的接触仍高于 0.7.2；极端采样也仍有保守手臂接触判定。本版不宣称所有手臂接触均已消除。

### 原生客户端性能

同机复制测试世界、1000×680 窗口、DISPLAY5，按实际 `RenderFrameEvent.Post` 的 `System.nanoTime` 时间戳测量。关闭垂直同步的六场对比，每场预热 3 秒，常规场景采样 8 秒、综合压力场景采样 30 秒；压力包含每秒 4 次点刺意图、边界瞄准、移动及真实铁盔甲。两版点刺时序均为 4 tick。新版等待实际服务端装备和拔刀就绪后才开始预热。

| 场景 | 0.7.2 帧间隔 P99（ms） | 0.7.3 帧间隔 P99（ms） |
| --- | ---: | ---: |
| 持枪待机 | 10.57 | 7.00 |
| 边界瞄准 | 16.60 | 5.98 |
| 持枪移动 | 11.91 | 5.05 |
| 点刺与扫击 | 17.53 | 5.43 |
| 30 秒综合压力 | 14.79 | 5.33 |

五个持枪场景的 P99 均降低，比值中位数为 0.3605；本轮旧版共 18 个超过 50 ms 的帧，新版为 0，新版六场最大帧间隔为 19.51 ms。后台负载、JIT 和窗口活动状态会影响同机测量，不能据此承诺任意环境的固定 FPS。无武器控制场景独立保留，不计入持枪改善门槛；完整分布、最大值、GC 与回退项见 `verification/spear-realtime-20261016/comparison.json`。

另按用户实例的 **垂直同步、120 FPS 上限、12 区块视距** 独立复核：预热 8 秒，持枪压力采样 30 秒，平均 **116.99 FPS**、帧间隔 P99 **15.09 ms**、最大 **31.24 ms**，没有超过 50 ms 的帧。所有运动与实际提交姿态检查均达到 30 Hz；本轮录像单独采集 **778 个实际渲染帧，155.95 Hz**，最大源帧间隔 18.68 ms，保留原始 PNG、逐帧时间戳与同一 tick 内的变化，录像开销不混入性能采样。

## 完美格挡与反击

默认完美格挡窗口为 **2 tick = 0.1 秒**。成功后，攻击者硬直 **4 tick = 0.2 秒**；对怪物同时停止移动和 AI 出招，硬直结束恢复原行为，不写入永久 `NoAI` 状态。已经射出的箭继续飞行，原有完美格挡反弹规则保留。

完美格挡成功后的 **4 tick** 内，下一次被服务端接受的左键攻击获得 **1.5 倍普通攻击伤害**。拒绝或尚未执行的缓存输入不会提前消耗机会；右键与命名技能不触发或消耗该左键机会。受击、闪避、收刀或换武器档位会清除机会。该窗口独立于既有西洋剑右键还击和闪避还击。

`combat.json.perfectGuardCounter` 配置 `windowTicks` 与 `damageMultiplier`；各档位完美格挡和硬直仍由 `styles.json` 的 `guard` / `heavyGuard` 定义。原本禁用完美格挡的重格挡与弓档位保持禁用。
