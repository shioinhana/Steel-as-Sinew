# 旧版分支技能迁移对照（0.9.0）

本文记录旧 ActionCombat 0.1.1（`C:/Users/34003/Desktop/actioncombat_legacy_20260923`）的**全部分支技能**在 FSRPG 0.9.0 中的落点，用于逐项验收。旧版源码是行为权威；旧版 docs 与本表冲突时以源码为准。数值与默认配置见 `config/fsrpg/skill_trees.json`、`src/main/resources/defaults/` 与 [0.9.0 版本说明](release-0.9.0.md)。

## 1. 移动 / 步法

| 旧版节点 | 旧版源码 | 新版实现 | 关键行为 |
| --- | --- | --- | --- |
| `RABBIT` 脱兔 | `FootworkAbilities.rabbitStep`、`CultivationMovement.startRabbitDash` | `movement/FootworkServer.style` + `rabbit` | B 发动，3 格瞬时位移、速度保留、碰撞裁剪；8 tick 无敌、12 tick 冷却；可同时攻击 |
| `FLYING_SWAN` 飞鸿 | `FootworkAbilities.flyingSwan`、`CultivationMovement.applyDirectionalCurve` | `FootworkServer.style` + `FootworkMath.swan` | B 发动，沿输入方向速度变换 `x+ln(x)+0.5x`；30 tick 冷却、8 tick 闪刺窗口 |
| 闪刺组合 | `ServerCombat.rapierThrust` + `CombatDamage.flashThrust` | `RpgServer.flashThrust` + `FootworkDamage` + `data/fsrpg/damage_type/flash_thrust.json` | 脱兔/飞鸿窗口内真实刺击命中追加 50% 无视护甲伤害；100 tick 组合冷却 |
| `CLOUD_STEP` 登云 | `FootworkAbilities.cloudStep`、`CultivationMovement.cloudJump` | `FootworkServer.jump` / `airJump` / `highJump` | Space 空中跳 +1；4 tick 间隔；G+Space 高跳 ×2 高度 |
| `CLOUD_STEP_II` 登云二 | `FootworkAbilities.cloudStepTwo` | `FootworkServer.special` | G 空中踩头（4 格，最大生命 2% 向上取整）或蹬墙（2 格，反向水平速度）；24 tick 共享冷却，不耗空中跳 |
| `CLOUD_STEP_III` 登云三 | `FootworkTechnique.CLOUD_STEP_III` | `FootworkView.cloudTier` | 空中跳 3 次，总 4 段 |
| `LIGHT_BODY` 若轻 | `CultivationAbilityHandler.airDragFactor`、`CultivationEvents` | `FootworkPhysics` + `FootworkTravelMixin` + `progression` 逻辑 | 空中水平阻力减半，重力不变 |
| `LIGHT_BODY_II` 若轻二 | `CultivationAbilityHandler.applyLightBodyTwoJump`、`CultivationEvents.onLivingFall` | `FootworkServer.onJump` + `RpgServer` LivingFallEvent | 地面/登云跳 +10 m/s 水平冲量；取消摔落伤害 |
| `LIGHT_BODY_III` 若轻三 | `FootworkAbilities.dodgeCooldownTicks` | `FootworkState.styleAccepted` | 取消脱兔/飞鸿冷却；登云间隔与踩头/蹬墙冷却保持 |
| 选学额度 | `CultivationService.select`（每 150 步法一次） | `ProgressionService.footworkView` / `blockers` / `learn` | 流派不占额度；6 个技巧各消耗 1 次；旧世界迁移不赠送 |

键位：旧 Shift（流派）→ 新 **B**；旧 C（空中特技）/C+Space（高跳）→ 新 **G** / **G+Space**，因为新版 C 已是格挡、Shift 已是地面突进。两者均可在原版按键设置改绑。

## 3. 西洋剑（剑）

| 旧版节点 / 机制 | 新版实现 |
| --- | --- |
| `RAPIER` 入门 | `rapier` 节点；0.8.5 五段击剑（直刺/换线刺/压剑刺/短回切/弓步终结刺） |
| `RAPIER_THRUST` 刺击 | `rapier_thrust` 节点 + `sword_thrust`/`rapier_charge`；7/2/2 tick、伤害 9、距离 4、20 tick 冷却、6 m/s 推进 |
| `RAPIER_PARRY_THRUST` 蓄力拨挡刺 | `rapier_parry_thrust` 节点 + `rapier_riposte`；16 tick 满蓄、未满受击抵消、满蓄受击破防 200 tick、伤害 18 |
| `RAPIER_EXECUTION` 缺血处决 | `rapier_execution` 节点；突刺命中追加缺失生命 10% |
| 拨挡还击 / 闪步回刺 | `styles.json` rapier `techniques`（0.9.0 默认启用 `rapier_riposte` 20 tick / `rapier_reprise` 12 tick；`RapierTechniquesMigration` 只补旧默认空值） |
| 完美格挡反击 ×1.5 | `CombatActor` 完美格挡反击窗口；0.9.0 修复按住 C 续包取消攻击 |

旧版四段随机、0.45 秒连击门等已被 0.7.5–0.8.5 发布设计替代，未回退。

## 5. 旧版未实现/被替代项

- `BOXING`（拳击）：旧版枚举存在但从未实现，不在本轮范围。
- 旧版长枪动作与数值保持 0.8.5 现状，本轮未改。
- 本轮不引入 0.8.0 设计稿中的 16 个新武器技能（踏锋刺、燕剪等），它们是提案而非旧版功能。
