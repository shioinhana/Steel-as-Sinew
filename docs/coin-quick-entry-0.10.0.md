# 硬币快速抛接

四种硬币取出时立即从画面下方向上抛出，手腕短促发力后退下，再回到硬币下方接住。取消原先占全程 22% 的持稳等待，默认完整展示由 1.05 秒缩短为 0.55 秒；约 0.44 秒落手，随后手与硬币一起缓冲并稳定。

飞行中的硬币采用独立轨迹，绕自身中心翻转一周，不被手腕晃动拖着走。接住时手先回到落点，再把硬币切回真实手部渲染变换，避免悬空缓冲或位置跳变。保留原皮肤、袖层、左右手、数量更新不重播与旧物品收回路径。钱袋的先抛后掂两下和冒险者牌保持原样。

客户端 `importedCoinEquipSeconds` 默认值更新为 0.55；安装时只把已识别的旧默认 1.05 迁移为 0.55，其他自定义值保留并先备份。

本改动与西洋剑工作统一并入 0.10.0 安装包。`workbench/coin-0.9.7-build/` 的 0.9.7 JAR 仅用于隔离候选验收，不单独部署。独立证据位于 `verification/imported-coin-quick-20261024/`，最终验收必须覆盖合并后的同一发行 JAR。
