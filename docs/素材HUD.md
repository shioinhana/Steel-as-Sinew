# 0.3.2 素材 HUD

本次按用户参考图安排底部布局：左侧上生命、下经验，中央为原版九格快捷栏，右侧上灵力、下体力。生命为红色、灵力为青蓝色、经验为绿色、体力为玉绿色，颜色与边框来自用户给出的四套横条素材。

条内显示生命当前值/上限、经验等级与当前级进度、灵力当前值/上限和体力当前值/上限。生命使用 Minecraft 玩家生命值；经验使用原版等级与升级进度。灵力对应原有 `spirit` 资源，体力对应 `stamina`，读取已有服务端快照，不改变资源上限、恢复、消耗或战斗判定。收到快照前，资源以空槽和 `--/--` 显示。吸收生命在生命文本后追加金色数值，并在条底部以金线提示。

四条在收刀、拔刀、生存、冒险与创造模式中显示；旁观模式、F1 和摄像机转向其他实体时隐藏；打开任务、种子奖励和背包窗口时，在窗口背后继续显示。原版快捷栏、物品数量、耐久、副手与攻击冷却指示继续使用官方渲染。护甲、饥饿、氧气、坐骑生命仍保留。原版定位条和坐骑跳跃条也保留，仅取消当前实际选中的经验条和原版等级文字。

界面宽度足够时，四条和快捷栏共用底部两行高度。GUI 缩放过大或副手占用空间时，两侧条自动合并为快捷栏上方的两列，给护甲、饥饿、氧气和物品名称留出位置。界面坐标跟随原版 GUI 缩放。

客户端 `config/fsrpg-client.toml` 的 `materialHud` 默认 `true`。改为 `false` 后恢复原生生命与经验显示；拔刀时原有左上角战斗资源文字仍显示。此选项只改变客户端显示。

安装时将旧 FSRPG JAR 移出 `mods`，放入 `fsrpg-neoforge-0.4.0.jar`，保留已有 FSVOXEL 0.6.0 依赖。多人游戏客户端与服务端使用同一版 FSRPG。本轮更新包无需覆盖外部 `config/fsrpg/models`；生物动作素材暂未接入。

开发验证使用 `hudPresentationTest` 和独立 `-PhudSmoke -PrpgJarSmoke`；实机使用有标记的复制测试世界，并核对窗口中心位于 Windows `DISPLAY5`。证据保存在 `verification/hud-20261011/`。素材来源、解包与分层记录在其 `assets/` 子目录。
