# YSM 包

| 路径 | 内容 |
| --- | --- |
| `packs/actioncombat_vanilla/` | 太刀动作 1:1 转 YSM 骨骼的文件夹包 |
| `packs/actioncombat_vanilla.zip` | 同上，可丢进 YSM `custom` |

拔刀人偶：

- **未装 YSM 模组**：隐藏原版玩家，播内置 `ysm_player` / `ysm_player_dual`（GeckoLib）。
- **已装 Yes Steve Model**：不隐藏原玩家、不画人偶，游戏里选中的模型就是演示外形。

本模组不再内置 `.ysm` 解密加载器，也不再自动导入鲸鱼娘包。
