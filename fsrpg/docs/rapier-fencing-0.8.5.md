# 0.8.5 西洋剑五段动作

这是一套用于 Minecraft 的游戏化五段编排，不是历史剑术中的固定套路，也不声称完整复原某一流派。四次刺击与一次短回锋切击共用前指剑尖、侧身站架和紧凑回收，取消旧版抬剑过头的大幅挥抡。攻击、伤害与资源仍由服务端决定。

## 原始资料与取舍

参考 Ridolfo Capo Ferro 1610 年《Gran Simulacro dell’Arte e dell’Uso della Scherma》的原文转录和原版图册。第八章讨论稍屈持剑臂、前臂与剑线、另一臂的配重；第十二章讨论身体、腿与手臂协同向前，以及同等距离下刺击的优势。因此新素材以剑尖持续威胁前方、短促伸展和共同支撑为主。[原书第八章与第十二章转录及图册](https://wiktenauer.com/wiki/Ridolfo_Capo_Ferro_da_Cagli)

第二段借鉴脱剑换线（cavazione）：剑尖小幅下绕后换线，而不是大幅抡臂。[原书扫描页 56：脱剑与反脱剑](https://wiktenauer.com/wiki/Page:Gran_Simulacro_dell'Arte_e_dell'Uso_della_Scherma_(Ridolfo_Capo_Ferro_da_Cagli)_1610.pdf/56)

第三段借鉴先取得剑线控制再刺入的意图；这里只表现紧凑拨压轨迹，不凭播放动作自动获得格挡。第四段保留一记短切作为游戏节奏变化；原文更偏好控制对方剑后以刺击回应，因此这段明确属于游戏化取舍。[原书扫描页 85：内外取得剑线](https://wiktenauer.com/wiki/Page:Gran_Simulacro_dell'Arte_e_dell'Uso_della_Scherma_(Ridolfo_Capo_Ferro_da_Cagli)_1610.pdf/85)

## 五段与服务端时序

| 次序 | 稳定技能 ID | 动作 | 前摇 / 有效 / 后摇（tick） |
|---|---|---|---|
| 1 | `sword_left` | 直线刺：小幅预备，剑尖直进，短促回收 | 3 / 3 / 3 |
| 2 | `rapier_downcut` | 脱剑换线刺：先低绕换线，再向前伸展 | 3 / 3 / 3 |
| 3 | `rapier_crosscut` | 拨压后刺：紧凑外侧压线，再沿新线刺出 | 3 / 3 / 3 |
| 4 | `rapier_light_thrust` | 短回锋切：以肘腕带动小弧线，避免过头抡剑 | 3 / 3 / 3 |
| 5 | `rapier_lunge_finish` | 弓步终刺：前脚支撑扩展、躯干小幅前送、回收归架 | 4 / 3 / 5 |

旧四个技能 ID 保留以兼容配置与存档；显示名和新动作语义以当前五段为准。第五段增加 `legacy_rapier_attack5`、`legacy_rapier_attack5_upper`、`rapier_attack5`。第三人称与独立第一人称素材均覆盖五段；既有右键突刺、闪避、格挡等源动作不由本生成器改写。

源素材按 120 Hz 采样，并额外保留归一化阶段点。连续时钟把前摇结束映射到源 `.26`，有效帧结束映射到 `.86`。下一段起点等于上一段有效帧末的真实持剑姿态，宽松预输入直接衔接，不先回默认手位；没有续招时，独立后摇从 `.86` 返回新击剑站架。自然收招后继续段位的点击只对真实当前姿态做短入口过渡。

## 身体与物品约束

手掌路径在角色空间生成，由两段各 37.5 cm 的手臂解算肩肘；腕部和官方剑物品定位保持同一握点。官方剑贴图长轴由现有原版物品变换校准，不以代理剑网格替换。刺击接触阶段剑尖保持前指，左臂配重，新增反作用向量不超过 3°；与真实移动倾斜合成后共用 5°总边界和既有平滑状态。

站定时前后脚落点与终刺的前脚扩展交给既有双腿支撑求解器；共享骨盆和腰口变形保持上下身连接。每段有效帧结束时，扩展脚步平滑回到共同落点，包含第五段接第一段，防止缓存续招时脚底突然收回。实际移动时淡出站定落点，由真实步态接管；这只是渲染，不给实体增加位移、伤害距离或根运动。

可复现素材生成器为 `tools/rework-rapier-fencing-085.py`；精确 0.8.4 → 0.8.5 两模型 SHA、改写动作与未改写数量记录于 `rapier-fencing-0.8.5-manifest.json`。纯检查覆盖真实官方剑轴、有效帧内速度峰值、起手立即运动、有效帧末衔接、自然回架、骨长、组合倾斜、同时间重复采样及弓步腰口。实机另使用 `RapierFencingReview` 的原生 Post 渲染捕获，纯测试不代替游戏验收。
