# 近战相杀与双刀手位

玩家对玩家、玩家对怪物的近战，在双方已经发起攻击的情况下，以实际接触时间相差不超过 2 tick（0.1 秒）判定相杀。无需同向挥斩；西洋剑突刺、双刀联动、长枪扫区和弓近战撞击也进入近战判定，飞行箭矢保持原判定。

比较伤害包含实际出手武器、修行加成和已消费的反击倍率，随后才交给原版护甲。差不超过 3 点时双方格挡、零伤害；差超过 3 点时只有优势方的“伤害差减 3”落实，且优势方获得完美格挡机会，劣势方进入配置中的弹反僵直。10 对 6 产生 1 点护甲前余伤。相杀不再追加普通格挡体力费用，真实接触保留原攻击全额成本。

只有已经出手的反向攻击才获得最多两 tick 抵达机会，普通单向命中不延迟。接触时立即锁定技能序列、伤害和出手物品，防止短有效帧被误算空挥。格挡和闪避按真实接触时状态处理，之后新按 C 不会倒挡旧伤害。怪物始终只调用一次完整原版攻击，保留毒、附魔与原生命中效果；取消或相杀抵消不重复重放伤害。

`combat.json` 可选字段 `weaponClash` 的默认值是 `{"contactWindowTicks":2,"damageTolerance":3}`。窗口单位 tick、允许 0–10；容差单位生命值点、允许有限值 0–1000000。旧配置省略整个对象即使用默认值，已有文件不必重写；显式提供对象时必须填全两字段。旧 `clashFacingArcDegrees` 和技能 `clashable` 字段保留兼容，实际相杀采用真实互达的技能几何，不再额外按输入方向排除。

默认 `legacy_dual` 的同向第三刀会在扣费、消费反击机会与写入缓存前被拒绝。完整自然收招归中；进入后摇、取消后摇、反复开关格挡均不会提前归中。双手反向实际移动后可恢复对应方向，联动斩与原有长时间空闲复位保留。自定义固定手 `dual` 模式继续保持原约定。
