# 0.8.0 滞空惯性层

普通滞空继续保留离地前的动作，新增的变化只来自玩家实际位移速度与加速度。上升时身体与腿轻微滞后，下落时逐渐释放，经过顶点时连续过渡；横向速度和转向加速度带来少量侧倾。没有独立的循环摆动，不改变玩家速度、位置、碰撞体、攻击时序或服务器战斗状态。

`AirInertia.State.observeMotion` 用实体 `tickCount` 去重，读取实际世界位置，并由相邻模拟 tick 的位移计算格/tick 的速度以及格/tick² 的加速度。首次观察才使用 `position-xo/yo/zo` 的回退速度；不能每次根据渲染插值字段估计速度。超过五个 tick 的缺口、回拨或大幅瞬移重置响应，避免错误速度把角色甩动。

滤波时间常数为 1.8 tick（0.09 秒），在模拟观察点更新，并在两个观察点之间按指数响应解析采样。`sample` 的 `renderTick` 是每秒 20 tick 的单调表现时钟，用于重复采样缓存和回拨检测；`partialTick` 是原版当前模拟插值比例 0..1。同一时间点在 30/60/120 Hz 的结果相同，皮肤、盔甲与手持物重复提交不累计运动。

表现层强度取 0..1。0 精确返回基础姿态、原世界矩阵和原下身对象，不残留晃动。满强度硬上限为身体前后倾 3°、侧倾 1.6°、腿部前后摆 4°、侧摆 1.5°。离地约 0.125 秒内渐入；落地清除。READY 使用完整响应，真正攻击的前摇、有效段、后摇只保留 25% 响应；格挡、受击僵直、闪避、拔收刀优先，附加响应为零。

上身、双臂、手、官方物品挂点共用绕实际腰口的刚体变换。相对于胸部的全部握链保持，双手持枪或持弓不被分别修改；头部保持颈部连接，剑与弓的头部方向只跟随身体变化的 65%。长枪完整运输头部，保留既有避碰空间。长枪边界握姿的腰椎安全包络可能随着倾斜变大，因此最多八次固定预算的简单整杆碰撞检查只减小附加躯干倾斜，不重新运行双手 IK，不改变既有握姿。双腿绕原髋关节轻摆，原膝弯、关节位置、骨长与缩放保持。原支撑下身的腰带与髋盖连接继续使用已有变形模型。

集成顺序：

1. 正常计算来源动作与实际握姿。
2. `AirPose.State.sample` 保留离地姿态；空中攻击继续走 `AirPoseJoin.align` 与离地下身合并。
3. 将尚未添加惯性的基础结果写入 `AirPose.State.presented`。
4. `observeMotion`、`sample` 后，以基础 local/world/supportedLower 调用 `AirInertia.apply`，只把该最终结果送往渲染。

不能把惯性输出写回 AirPose 的基础帧，否则下一帧会再次叠加并发生漂移。同一角色 State 可以跨同装备的阶段绑定保留；presentationKey 应包含装备、模型与皮肤。换装备时新 key 重新渐入；世界、维度、死亡、卸下装备或清空模型时清除 State。

独立 Java 21 验证：`AirInertiaTest` 通过 **32,775 项检查**，覆盖四套正式武器骨架及全部现有片段、普通/细臂、最大附加角度、来源不可变、重复采样、强度禁用、上升/下降与顶点连续、动作优先、瞬移重置以及实际长枪 18 个瞄准组合。30/60/120 Hz 共同采样点最大差 **0°**；腰口最大数值残差 **0.0000688 cm**，胸部相对握链最大残差 **0.0000763 cm**。原生游戏效果和最终发布构建另由主任务验证。
