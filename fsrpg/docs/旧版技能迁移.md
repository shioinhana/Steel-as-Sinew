# 0.5.0 旧版技能、修行与动作迁移

本次来源为 `C:/Users/34003/Desktop/actioncombat_legacy_20260923`，对应旧 ActionCombat 0.1.1。原“单剑 / 双剑 / 弓术”映射为 FSRPG 的“西洋剑 / 双刀 / 弓”。长枪操作、动作和配置保持原样，用户提供的生物动作素材继续搁置。当前完整构建、真实客户端验收和部署仍未完成，本文件记录实现与默认配置。

## 来源与迁移范围

成长与条件依据旧 `CultivationConfig`、`CultivationRequirements`、`CultivationData`、`CultivationEvents`、`CultivationCombat` 的实际代码，招式与数值依据 `ServerCombat`、`WeaponCategory`、`CombatAttributes` 和 `CombatConstants`。旧代码实际单剑为四连；如梭实际是 **5 发储备、20% 减时、60 tick 恢复一发**，采用实现值而非旧注释里的四发 / 25%。

旧动作资源转换为现有 FSVOXEL：`legacy_rapier.fsvoxel`、`legacy_dual_blade.fsvoxel`、`legacy_bow.fsvoxel`，第一人称各有对应 `_fp.fsvoxel`。仍由当前 FSVOXEL 接入官方玩家、皮肤、盔甲和 ItemStack 渲染；无需把旧模组的动画运行依赖一起装入新 FSRPG。

现有稳定技能 ID 继续保留：西洋剑首段 `sword_left`，突刺 `sword_thrust`；双刀四种手位 `dual_ll / dual_rl / dual_rr / dual_lr`，新增合击 `dual_combined`；弓以 `bow_bash`、两种 `bow_*_charge` 与 `bow_*_release` 记录表现。旧第五段、旧左右攻击、拨挡还击与闪步回刺 ID、旧 `rapier.fsvoxel` / `dual_blade.fsvoxel` 资产保留供已有配置使用。默认操作已经转为四连、蓄力拨挡刺、方向双刀和两模式弓。

## 基础修行与真实成长

有效睡眠跳过夜晚开启心法；在线真实计时累计 3,456,000 tick 增加心法 1 点，不把睡眠或命令导致的世界时间跳变算在线时长。首次实际吃完一种具有原版 FOOD 组件的食物增加心法 1 点；实际恢复饥饿值每累计 10 点再增加 1 点。满饥饿时实际消耗的新食物仍可记录种类，药水等非食物不计。

开启心法后，累计实际承受敌对生物造成的最终生命损失 10 点开启煅体；其后每次敌对攻击接触增加煅体 1 点，被挡住也算，同一攻击者同 tick 去重。自主地面走跑累计 100 米增加煅体 1 点，实际破坏 50 个方块增加 1 点。煅体累计 5 点后开启步法，每自主地面 50 米增加 1 点，默认上限 600。水中、飞行、骑乘、传送、闪避、刺击推进和外推位移不算自主地面训练；新开启能力不追补之前的移动。

西洋剑直接猎杀敌对生物增加剑分；双刀实际命中活体增加双刀分，空挥不计，旧实现不要求目标必须敌对；弓由实际箭矢猎杀敌对生物增加弓术分。试炼与末影龙条件由实际服务器事件记录。双刀层数是战斗状态，命中叠层，100 tick 无命中掉一层，与累计成长分分别保存。

根骨和悟性首次随机整数 -30%～+30%，小数成长余数持久化。根骨影响心法 / 煅体收益，悟性影响步法 / 武器成长；实际 Boss 击杀增加永久悟性 10%，最终收益系数最高 200%。例如当前效率 70% 时，10 次有效击杀累计 7 分，不能直接把节点要求的“80 分”等同于 80 次击杀。

心法 4 / 8 / 16 / 32 / 64 各增加生命 2 点；10 点且食物值 20 时自然回血间隔减半，50 点将低食物回血门槛降至 16，之前保持原版 18。煅体 10 / 20 / 40 各加伤害 1 点；15 / 30 各缩短攻击间隔 0.04 秒，间隔不低于 0.12 秒；各攻击速度档拉弓时间乘 0.9，煅体 5 / 15 / 25 / 35 各使挖矿时间乘 0.95。步法到 600 时移动加成达到 20%。

长时修行默认按 **UTC 日期**结算：基础总值与可用值每日乘 0.95，逐日取整；某武器连续 3 天无有效成长，其分数乘 0.9，并继续按三天周期结算。日期、最近成长和小数余数均保存，重复登陆不重复衰减。`rules.longTerm.enabled: false` 可关闭缺席衰减。

## 当前武器动作规则

西洋剑左键是四段，不再默认第五段。普通右键突刺前摇允许攻击 / 格挡 / 闪避取消，取消不开始突刺冷却；有效判定提交时一次性施加沿三维视线的 6 米/秒推进。解锁拨挡后，按住右键保持蓄力前摇，松开才提交；未满蓄受击抵消并蓄满，下一次满蓄受击会破防。拨挡后的释放不使用普通 20 tick 冷却，死亡和收刀等强制状态取消蓄力。

双刀默认方向控制：归中开始，左键先左手左斩、再右手左斩；右键先右手右斩、再左手右斩。两刀已经在同侧时不能第三次向该侧出刀。双键合击冷却 100 tick，合击复位；40 tick 不攻击也归中。原来的 `controls.mode: "dual"` 继续保留，默认新模式为 `"legacy_dual"`。持刀 +15%、挥砍额外 -35%、每层挥砍 +15% 是加法，不能将三个比例相乘。

弓速射 / 狙击完整引弓默认 10 / 30 tick，箭速 3.0 / 3.6 格每 tick，最低释放蓄力比例 0.2。速射每 5 分缩短 1% 引弓，最多 30%；狙击每 3 分箭速增 1%，最多 100%。如梭的 20% 与速射减时相加，总减时上限 50%。速射 / 狙击每次发射耐久消耗 1 / 3；左键撞击距离 2.5、伤害 4、击退 1.4、冷却 7 tick。

## JSON、单位与参数优先级

| 定义 | 权威内容与单位 |
| --- | --- |
| `config/fsrpg/skill_trees.json` 的 `nodes` | 稳定 ID、总值条件、学习成本、前置、互斥组、技能引用与效果；数量均为整数 |
| `rules.training` | 真实在线 tick、米、生命 / 饥饿点数、挖矿数量和各属性档位；攻击间隔字段以秒表示 |
| `rules.rapier` | 特殊突刺的 `windupTicks / activeTicks / recoveryTicks / cooldownTicks / fullChargeTicks / guardBreakCooldownTicks` 均为 tick；`lungeSpeedMps` 为米/秒；`range` 为格；伤害为生命点，倍率和缺血比例为小数 |
| `rules.dual` | 移动加成 / 惩罚为加法比例，`decayTicks` 与 `linkedSlashCooldownTicks` 为 tick |
| `rules.longTerm` | UTC 天数、每日 / 周期乘数、初始资质与永久资质边界 |
| `config/fsrpg/skills.json` | 其它动作时序、资源消耗、伤害、距离、角度和模型引用；特殊突刺的时序 / 伤害 / 距离由 `rules.rapier` 覆盖 |
| `config/fsrpg/archery.json` | 弓实际引弓时长、箭速、耐久、分支参数、撞击和动画持续 tick；`*ArrowSpeed` 为格每 tick，比例为小数 |
| `models/*.fsvoxel` | 动作采样时间为秒；服务端仍以每秒 20 tick 判定 |

例如 16 tick = 0.8 秒，6 米/秒 = 0.3 格每 tick。修改特殊突刺应改 `skill_trees.json.rules.rapier`；K 窗口对 `skills.json` 的普通技能时序编辑不会反向改这组规则。弓 `autoChargeScore / trajectoryScore / scopeScore` 必须与技能树对应节点的 `requirements.score` 相同，整集校验拒绝只改一侧。

`schemas/skill_trees.schema.json` 与 `schemas/archery.schema.json` 提供类型、边界和结构；服务端额外校验未知字段、有限数值、唯一稳定 ID、前置环、效果归属、互斥组以及技能 / 档位引用。全部定义通过后 `/fsrpg reload` 才替换运行配置，失败保留原定义。

## 0.4 配置与旧存档迁移

JAR 内保留 `defaults/legacy-0.4/skills.json`、`styles.json`、`weapons.json`，作为旧默认 baseline。首次升级比较当前字段与 0.4 baseline：仍等于旧默认的字段更新到新默认；不同的字段作为用户自定义保留；新增节点、动作和武器档位补入。对象逐字段处理，自定义数组继续保留。若模型或动作引用已自定义，保留该模型 / 动作对；未知稳定 ID 也保留。

迁移先整体校验，然后将原来的三个 JSON 原文保存到 `config/fsrpg/legacy-skill-backup-v1/`，完成后生成 `legacy-skill-migration-v1.json` 标记，之后重载不重复迁移。第一次写入可能改变 JSON 空白和缩进，备份保留原文；`models/` 文件不由此过程覆盖，世界数据不删除。已有自定义五连数组可以保留五连；未改的旧默认五连会更新为新版默认四连。

服务器读取旧世界 `resources.json` 中已有玩家 UUID，以此识别已有战斗角色，首次为其保留西洋剑、双刀、弓三树基础能力。该迁移不赠送修行点数、进阶成长分或高阶节点；进阶按旧条件解锁。新角色走有效睡眠、实际训练和付点学习的流程。三树入门保留后不会因基础点数不足突然失去基础动作；长枪保持现有可用规则。

定义保存在 `config/fsrpg/skill_trees.json`，玩家数据保存在 `<世界>/data/fsrpg/skill_trees.json`，不能互换。玩家存档按 UUID 保存已学节点、累计 / 可用值、三武器分数、食物种类、训练余量、资质、UTC 日期和双刀层数计时；弓技能资源另在 `<世界>/data/fsrpg/archery.json`。世界之间不共享进度，删除配置节点时其稳定 ID 仍留在存档中，之后恢复定义可重新识别。
