# 0.10.0：西洋剑挑、劈、刺、砍与动作分支

Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21，网络协议仍为 12。

## 动作与操作

左键五段改为直刺、斜挑、斜劈、短横回砍、弓步终刺。稳定技能 ID、已有伤害与体力数值保留；前四段前摇/有效/后摇为 3/3/3 tick，末段为 4/3/5 tick。攻击期间任意阶段可预输入一招，当前有效判定完整结束后接续；不继续输入则各自自然回架。自然收招后仍保留默认 12 tick 续段时间。

左键攻击中右键可缓存一次普通突刺，松开右键不会丢失已缓存的突刺。左键可替换这一个缓存槽；右键分支的接触结束后可以再接左键第一段。独立按住右键仍按已学习的技能进行蓄力。成功拨挡后右键还击、完成闪避后右键回刺重新接入真实服务端输入路径；相关技能解锁和窗口条件继续生效。格挡、闪避、界面取消和体力不足均清理相应缓存，不会延后误出招。

## 人体与上下身联动

第三人称与独立第一人称重新制作 120 Hz 素材。第三人称双臂及第一人称持剑臂的上臂和前臂各 37.5 cm，肘屈 10–135°；持剑前臂轴向旋转不超过 30°，实际前臂与剑轴之间的腕部弯折不超过 34°。剑柄使用刚性握持关系，剑仍由实际 ItemStack 的官方渲染器提交。第三人称左臂随躯干配重，第一人称左臂保留既有单骨结构做小幅配重，不计入双骨 IK 和肘角检查。短横砍保持面向敌人，不大幅转身背敌。

第三人称避碰检查覆盖上臂远端、前臂及官方剑轴与胸腹、头部包围盒的相交。手臂检查的包围盒在横向和前后方向留出 9.375 cm 余量，排除上臂靠肩的近端 22%，肩颈连接端面不向内扩张；它限定了骨段与包围盒的关系，不等同于完整皮肤网格的逐面碰撞证明。

五段的有效帧末与下一段起点具有一致的骨骼姿态；作者连续曲线的端点切线归零，导出后的 120 Hz 线性/四元数插值仍有有限的首尾样本变化，因此保证交接姿态连续，不宣称实际播放速度严格连续。独立收招回到同一站架。非相邻招式与防御分支从实际当前姿态短暂过渡，第一人称也保留自己的腕部过渡状态。修复了第一人称的连段队列曾依赖不可见第三人称玩家采样才能释放的问题。

分支过渡的第一帧直接继承上一帧实际关节，随后沿最短旋转路径接入继续运行的目标动作。取消旧过渡中“先显示新姿态、再错误回补旧姿态”的回弹，以及把新动作首帧误当成旧动作速度的修正；这不改变服务端出招与接触时间。

移动继续使用长枪共用的双腿支撑、共同骨盆、分段腰口和转身踏步。西洋剑加入随真实距离步频变化的小幅晃动，与移动倾斜、攻击反作用合并后总倾斜最多 5°；攻击时减弱附加晃动，状态在招式之间连续继承。起步时站定脚位与移动脚位的转向支点改为连续混合，进行中的踏步转身不在微小移动输入时突然消失。停步后逐渐恢复前后脚站架，移动中让真实步态接管。
