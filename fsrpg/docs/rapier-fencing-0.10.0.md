# 0.10.0 西洋剑素材重做

本次是面向游戏连击的动作编排：直刺、斜挑、斜劈、短横回砍、弓步终刺。挑和劈在空间中具有相反的对角线轨迹，第四段由手臂与小幅躯干转动完成，不转身背对目标。保留五段稳定技能 ID，以及普通右键、蓄力、拨挡还击、闪步回刺的技能语义。

## 可复现素材

`tools/rework-rapier-fencing-0100.py` 生成两份模型：`legacy_rapier.fsvoxel` 和独立第一人称 `legacy_rapier_fp.fsvoxel`，同时同步工作区的 `config/fsrpg/models/` 模板。它不写运行中的 `run/client/config/`，不修改几何、官方物品载体、皮肤映射、其它武器和历史 `rapier.fsvoxel`。模型基线与输出 SHA-256 记录在 `rapier-fencing-0.10.0-manifest.json`。

攻击统一标记 `rapier_fencing:0100`，持势标记 `rapier_guard:0100`。蓄力动作单独标记 `rapier_charge:0100`，不能误用攻击时钟。片段保留 120 Hz 采样及额外阶段关键点；第三人称攻击只携带上身与基础髋向，实际下肢由运行时支撑与步态系统负责。

| 段落 | 素材标签 | 第三人称剑尖：预备到接触的位移（约 cm） |
|---|---|---|
| 直刺 | `direct-thrust` | 横向 0，向上 13，向前 29 |
| 斜挑 | `rising-cut` | 横向 +63，向上 90，向前 29 |
| 斜劈 | `diagonal-cut` | 横向 -51，向下 87，向前 42 |
| 短横回砍 | `return-cut` | 横向 +106，向上 23，向前 19 |
| 弓步终刺 | `lunge-thrust` | 横向 +1，向上 17，向前 32 |

这些数值是官方剑轴下的模型空间路径，不是实体根位移，也不扩大服务端判定范围。第一人称使用同样的动作意图，但肩位与手路径独立求解：保留四类轨迹，避免短前臂硬折腕以迁就镜头。

## 接续与人体约束

归一化 `.26` 为前摇结束、`.56` 为接触中心、`.86` 为有效阶段结束。上一段 `.86` 与下一段起点的身体、头、髋、双臂、手掌和物品姿态逐骨一致。作者的连续曲线在这两个端点的切线归零；导出后使用 120 Hz 离散样本及线性/四元数插值，首尾相邻样本仍有有限变化，因此保证交接姿态连续，不宣称实际播放速度严格连续。不接下一段时，从 `.86` 独立收回共同持势。手臂从首个实际 60 Hz 帧开始运动；最高剑尖速度处于服务端有效阶段。

第三人称双臂及第一人称持剑臂由两段各 37.5 cm 的连杆求解。右肘是固定解剖弯曲轴，允许 10–135°弯曲；前臂单独承担最多 30°旋前/旋后。手掌只做把前臂延长线对齐剑线所需的最短旋转，实际剑轴与前臂夹角不超过 34°。第三人称物品挂点保持固定握持旋转，与手掌位置完全重合，不能通过单独转动物品隐藏折腕。第一人称没有独立手掌骨，将同一个受限腕旋转折入官方物品挂点；其左臂保留已有单骨结构，只做小幅配重，不属于双骨 IK 或肘角检查的范围。

躯干基础侧身为 65°，攻击额外转动不超过 9°；头部反向补偿保持看向目标。第三人称非持剑臂的极向量在躯干局部解剖外侧，手保持身体外后方，小幅跟随转体与伸展。首次体积检查发现旧式世界空间极向量在转体时让左肘靠入躯干，已改正并重新全段检查。

## 验证边界

`tools/review-rapier-0100-assets.py --plots` 直接读取导出的文件，自行重建 FK，不调用素材生成器的 IK。检查源采样、格式、配置副本、第三人称双臂及第一人称持剑臂的骨长与肘角、实际剑轴腕角、逐帧转角和完整接续。第三人称另检查上臂远端、前臂中心线与躯干及头部包围盒的相交：包围盒在横向和前后方向增加 9.375 cm 余量，上臂靠肩的近端 22% 不纳入检查，肩颈连接端面不向内扩张。这是指定包围盒与骨段的近似检查，不是完整皮肤网格的逐面碰撞证明；官方剑轴另做躯干和头部相交检查。轨迹图与 JSON 报告位于 `verification/rapier-0100-assets/`。

`RapierFencingTest` 和 `RapierMotionTest` 使用真实 FSVOXEL 求值器与服务端阶段时钟，验证四种轨迹、实际速度峰值、固定握持、肘轴和腕限、条件分支、逐骨接续与腰口连接。源肘轨道的侧向旋转严格为零；原生四元数在同时变化的屈曲和旋前之间插值，会出现极小的中间侧向偏差，测试以真实肘轴偏差小于 0.1°约束。

这些模型与纯测试不替代游戏验收。本版已在 DISPLAY5 的真实客户端完成三视角五段攻击、四方向移动、转身启停、攻防分支与第一人称连击录制；2031 张原生帧独立核验、171941 项动态检查通过。最终抽帧目视覆盖腰口、肘腕、左臂配重、脚位与官方剑，遮挡部位结合实际提交矩阵核对。分支过渡修复为从旧姿态第一帧直接沿最短旋转路径接入，避免错误速度回补产生的反跳。完整统计、验证边界和安装记录见 [0.10.0 版本说明](release-0.10.0.md)，原生证据位于 `verification/rapier-renewal-20261024/game/`。
