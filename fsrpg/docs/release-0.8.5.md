# 0.8.5：右后越肩镜头、长枪浮动准星、西洋剑五段击剑

目标环境仍为 Minecraft 1.21.11、NeoForge 21.11.45、Java 21，网络协议保持 11。

## 实际操作

- 越肩镜头位于角色右后方。默认向右 0.65 格、向后 3 格，保留 0.12 秒位置响应、0.5 秒进出过渡和 2° 侧倾；碰墙仍限制最终位置。
- 长枪取消目标锁定。命中敌人不再强制镜头或人物追随目标；R 保留长枪自动拔刀。
- 长枪显示浮动准星，系统鼠标保持捕获隐藏，不显示限位框。全屏鼠标输入映射到缩小后的实际枪姿范围，左右各 31.5°、上下各 28°；摄像机俯仰仍限制在 ±24°。
- 准星偏移越大，视角转得越快。在中心附近仍可小幅移动枪尖；接近限位时连续加速带动角色转向。转向消耗偏移量，准星逐渐回中。持续输入可以连续转身，不会卡在原来的瞄准扇区。
- 准星世界射线同时用于实际攻击和可见枪姿，考虑右肩镜头到眼睛的视差。点按、长按保持、扫区和空挥体力规则延续；打开界面或失去焦点清除待转向输入并释放保持攻击。
- 西洋剑改为五段：直刺、换线刺、压剑刺、短回切、弓步终结刺。前四段前摇/有效/自然收招为 3/3/3 tick，末段为 4/3/5 tick；每段仍消耗 5 体力。连续点击可提前缓存下一招，接续点在完整有效帧之后。各段具体设计见 [击剑动作说明](rapier-fencing-0.8.5.md)。
- 西洋剑继续使用准星攻击锁定：角色朝向目标，镜头可独立转动，锁定时隐藏准星，R 解锁。

## 可调参数与兼容

客户端 `fsrpg-client.toml` 新增：

| 字段 | 默认值 | 含义 |
| --- | ---: | --- |
| `spearCursorCenterTurnSpeed` | 28 | 中心区域按偏移比例产生的转速，度/秒 |
| `spearCursorEdgeTurnSpeed` | 240 | 接近限位时增加的最大转速，度/秒 |
| `spearCursorEdgeStart` | 0.65 | 开始明显加速的归一化偏移 |
| `spearCursorTurnResponseSeconds` | 0.06 | 转速加减速响应时间 |

`spearLockedAimRangeScale` 保留旧键名和原自定义值，现在表示自由准星的枪姿范围比例，不再表示锁敌。默认 0.7。旧宽高字段仅作兼容读取。

四个既有西洋剑技能 ID 保持稳定，新增 `rapier_lunge_finish`。迁移以旧版原始模型、动作、连段和字段值为依据，备份后仅升级仍匹配原版的部分，保留自定义数值、技能链和模型；自定义动作链不会被强行接入缺少的第五动作。旧技能迁移使用冻结的 0.8.4 模板，避免较早存档绕过此检查。
