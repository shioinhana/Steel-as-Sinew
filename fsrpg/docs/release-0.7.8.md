# 0.7.8：明确选中、过肩镜头与动作衔接

目标环境为 Minecraft 1.21.11、NeoForge 21.11.45、Java 21。版本 **0.7.8**，网络协议 **9**，客户端与服务端需使用相同协议。完整构建、真实客户端准星 / 镜头与动作主实机、Shift / 长枪扫击独立实机、最终录像编码及正式实例部署均已完成。

## 拔刀、选中与镜头

非长枪武器装备后保持收刀，**R 拔刀 / 收刀**。长枪沿用唯一姿态自动拔刀。弓的 R 同样用于拔收刀，速射 / 狙击通过 **V 档位选择**切换。

非长枪武器在攻击被接受时，才尝试锁定准星明确选中的生物，默认上限 **10 格**。服务器校验实体 ID 与 UUID、距离、实际眼睛射线、方块及生物遮挡、友好关系和攻击是否能发出。默认允许明确选择普通生物；附近敌人不会自动入选，也不会把已有普通生物锁定抢走。无合法准星目标时仍可向当前方向出招，不自动补选其它敌人。

已有锁定时继续保持该目标，角色朝向和攻击随目标，鼠标独立转动镜头。目标死亡、越界或不再满足合法视线等条件时解除。**第一次 R 仅解除锁定并保持拔刀，随后再次 R 才收刀**。锁定不会扩大实际技能距离、忽略遮挡或改写既有多目标伤害规则。

没有锁定时，鼠标原始输入先改变当前镜头角度，再据该角度更新角色朝向；不再让身体追随上一帧镜头。过肩镜头从眼睛位置平滑移入，收刀后平滑返回，默认进出时间 **0.5 秒**，完成后恢复此前视角。镜头位置响应默认 0.12 秒，实际位置仍受墙体碰撞限制。

主副手有普通物品且未装备战斗武器时，R 可以单独开关过肩探索镜头。该本地 `cameraOnly` 状态不建立服务端拔刀、攻击或目标锁定；空手不启用。进入、退出和墙体安全使用同一套镜头路径。

## Shift 水平突进与续跑

拔刀后新按原版潜行键（默认 **Shift**），默认消耗 **5 体力**，沿当前移动输入方向突进；没有方向输入时向角色前方。默认指令轨迹在 **10 tick（0.5 秒）内累计 3 格**，按服务端时钟逐步加速，末步接到续跑速度；实际采样位移还受网络 / 物理应用边界及随后惯性影响，见下方测量。持续按住后沿本次触发的世界方向继续跑动，默认 **5.6 格/秒**，不会重复触发突进或反复扣费。

该运动仅修改水平速度，保留跳跃和下落的 Y 速度，继续服从原版碰撞。它不提供无敌，也不替换原 **Alt 闪避**。松键结束长按续跑；再次新按才尝试下一次突进。默认冷却 10 tick，输入租约 12 tick；持续输入定期续约，失焦、界面、不兼容状态或续约超时不会自动产生新的付费突进。

**Shift+C 优先重格挡**。格挡、受击硬直、闪避、拔收刀等不兼容状态会阻止或停止本次突进运动。攻击费用、空挥返还和体力回复继续使用 0.7.7 的规则；突进费用本身不作为攻击空挥退费。

## 单剑直接播放当前原稿

单剑原有宽松预输入与四连顺序保留：

```text
sword_left → rapier_downcut → rapier_crosscut → rapier_light_thrust
```

原换段逻辑会在新 binding 的第一帧先显示新片段的默认取样，下一帧又通过偏移衰减叠回上一刀末姿，造成“先回中位，再返回动作”。0.7.8 对源单剑攻击交接关闭这条偏移桥接，直接播放当前段原稿与现有接触时间映射。没有重画源关键帧，也没有缩短服务端伤害有效帧或重新收紧连击输入窗口。

单剑原 65°侧身、0.7.7 的额外腰扭 45°上限、下身直接跟随与踏步继续保留。这些站姿和支撑处理不用于重新混合攻击手臂的源曲线。

## 普通滞空保持姿态，攻击上下身保持连接

长枪、单剑、双刀和弓在普通跳跃 / 下落时保留离地前实际提交的动作姿态，不立即换成 jump / fall 守势，也不凭空产生格挡状态。正在发出的攻击可继续上半身原稿，下肢保留起跳姿态；动作结束后保持最后实际呈现的姿态，直到落地恢复自然待机或移动。

单独冻结腿骨仍不够：离地后地面支撑求解不再施加共同骨盆沉降，当前动作的整体位移也可能继续变化，导致上身腰口与固定下肢分开。运行时将当前上身的腰口世界点平移回保留骨盆的腰口，保留源关节旋转、比例、手臂与武器相对上身的动作。长枪与腰部重定位后的单剑使用 body 原点作为腰口，旧双刀 / 弓使用原躯干中心下方 31.25 cm 的连接点。源动作文件不改写。

真实主动 C 格挡、受击、闪避、拔收刀等权威状态仍可覆盖姿态保持，服务端格挡状态不由本轮空中展示创建。游泳、滑翔与骑乘不套用普通滞空保持。更换武器、模型或皮肤模型时，不把上一套骨架的冻结姿态套到新骨架。

## 双刀肩根轻微外移

双刀左右肩根各向外调整 **1.5625 cm**，约为原版模型 **0.25 像素**。这是肩根平移，整条前臂、手和官方 ItemStack 挂点随之移动；原动作旋转、骨长、缩放和手内握点不变。标准与纤细皮肤保留原适配差异，盔甲使用同一实际角色姿态，第一人称双刀也采用同量微调。

0.7.7 的源 `static_idle`、`walk_hold` / `run_hold` 循环与线性攻击时钟保留，没有恢复后来加入的双刀变速或跨动作偏移混合。

## 长枪扫击沿切向击退

长枪默认回收 14 cm、点按 0.2 秒、长按刺出保持、期间即时扫区判定和每挥刺每目标去重均沿用 0.7.7。扫中后，击退方向取命中处已接受准星轨迹的三维切向，默认强度为技能击退量的 **50%**，继续经过原版击退事件和目标击退抗性。

地面目标不接受向下冲量，纯向下扫击没有位移效果；斜向下扫的水平分量仍可生效。空中目标可沿下扫方向击坠，上扫和横扫使用各自切向。静止点刺没有扫动切向，继续沿用原点刺击退，不能借拖动重复命中同一目标。

大转身包间隙内仍暂停失效旧方向的伤害，画面枪向约束到当前前方，原保持租约不因此取消；新合法轨迹抵达后继续同次挥刺，不补扫暂停时的旧区域。极快连续路径仍共享每碰撞 tick 4096 条射线预算，并用保守覆盖余量处理压缩采样。

## 配置与迁移

服务端 `config/fsrpg/combat.json` 新字段默认值：

```json
"burstDash": {
  "distance": 3.0,
  "durationTicks": 10,
  "staminaCost": 5.0,
  "cooldownTicks": 10,
  "runSpeed": 5.6,
  "inputLeaseTicks": 12
},
"spearSwipeKnockbackMultiplier": 0.5
```

距离单位为格，`runSpeed` 为格/秒，其余时间为服务端 tick（20 tick = 1 秒）。持续时长、末端跑速和距离需满足配置校验的单调加速约束；扫击倍率范围为 0–1。

迁移只补缺失字段，已有自定义值和 Alt 闪避参数保留。原始 `combat.json` 备份到 `burst-dash-backup-v1/combat.json`，完成标记为 `burst-dash-migration-v1.json`，重复启动不重复迁移。原 `rapierTargetLock` 名称兼容保留，继续提供明确选中的开关、距离、普通生物和视线规则；名称不代表恢复自动选敌。

客户端 `config/fsrpg-client.toml` 的镜头配置：

| 字段 | 默认值 | 单位与用途 |
| --- | --- | --- |
| `thirdPersonWhenDrawn` | `true` | 拔刀时使用过肩镜头 |
| `rapierShoulderOffset` | `0.65` | 横向偏移，格；旧字段保留，供各武器和普通物品镜头共用 |
| `shoulderCameraDistance` | `3.0` | 眼睛后方距离，格；墙体可压缩实际距离 |
| `shoulderCameraHeight` | `0.12` | 额外高度，格 |
| `shoulderCameraTransitionSeconds` | `0.5` | 进出过肩镜头的过渡秒数 |
| `shoulderCameraResponseSeconds` | `0.12` | 转向、侧移和墙距变化的位置响应秒数 |

源单剑攻击不再套用 `actionBlendSeconds` 的上一动作偏移桥接；该字段仍服务其它原有过渡。腰扭、转步、长枪额外回收等既有客户端字段继续有效。格挡按键、金闪和可调提示时序沿用既有配置。

## 边界

10 格是默认明确选中距离，不是所有技能的伤害距离。镜头准星与角色眼睛之间存在第三人称视差，最终能否选中仍由服务器真实射线和遮挡判定。过肩镜头会因墙体压缩，Shift 的 3 格为无遮挡默认运动轨迹，不能穿墙或抵消竖直物理。

肩根微调不重画原始素材，极端姿势、盔甲厚度和外部自定义模型仍可能局部接触。空中下肢保持对应普通跳落，真实防御或受击可覆盖；上身只保留与固定骨盆兼容的整体位置，源局部动作继续。击退可以被事件取消或抗性削弱；已格挡、未造成真实伤害或零切向的接触不承诺产生切向位移。
