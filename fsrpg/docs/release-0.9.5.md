# 0.9.5：钱袋改为掌托持握

Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21，网络协议保持 12。

钱袋第一人称从袋口侧挂改为袋底由手托住。移除原来的袋口外侧挂点与悬挂倾角，将袋底中心放在原版手臂的承托位置，袋身向上；钱袋和真实皮肤手臂共用取出、掂动和切换时的收回动作。

保留 0.9.4 的钱袋大小、下沉蓄力—上掂—回落缓冲，以及原版皮肤/袖层、左右手和旧缓存物品收回逻辑。四种货币与五种冒险者牌的显示和动作不变。物品继续使用实际 ItemStack 的官方渲染状态，素材几何、贴图、GUI、第三人称和服务器逻辑不变。

现有客户端配置按原值保留。`importedPouchRaise` 仍是在持握基准上的额外抬高量，本版调整托举基准以给袋身留出视野；无需重置用户设置。

手臂绕真实拳顶承托点转腕，袋底中心与这个承托点重合。上掂阶段的转腕不会抵消手部上移；默认动作包含下沉、上掂、回落缓冲和回稳，结束后停止。
