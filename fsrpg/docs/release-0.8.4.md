# 0.8.4 锁敌、连续防御与西洋剑体态

长枪移除可见矩形区域。未锁敌时，鼠标每次输入直接改变越肩镜头和人物朝向，固定中心准星沿实际摄像机位置拾取世界，再转换为角色眼睛到目标的攻击方向。输入使用本次更新的镜头角度，避免快速转身时提交上一渲染帧的方向。点刺、长按保持、连续扫击轨迹和服务端前方限位继续生效。

保留镜头位置的 0.12 秒响应、进出越肩的 0.5 秒过渡、墙壁裁剪后的再次安全检查，以及原有枪姿、握点和腰腿跟随。新增 `config/fsrpg-client.toml.shoulderCameraRollDegrees`：默认轻微侧倾 2°，范围 −6° 到 6°，0 关闭，随进出镜头渐变。旧矩形宽高键保留兼容，不再影响输入与 HUD。未锁定时相机俯仰继续为 ±24°。准星对10格内生物攻击且服务端接受后建立锁定；R解锁但保持自动拔枪。锁定时人物和镜头共同跟随目标，捕获模式的鼠标及准星隐藏，鼠标控制枪姿，仍使用原有实时求解。不可见的整屏虚拟坐标映射到实际左右各31.5°、上下各28°，相对原45°/40°范围缩小30%；这不是把屏幕鼠标活动区缩小。虚拟中心保留目标仰俯方向，端点有界，窗口缩放不产生假输入，超出边缘不会转动锁定镜头。`spearLockedAimRangeScale` 默认0.7。西洋剑锁定也隐藏准星，其镜头仍保留独立转动。

普通完美格挡由当前 6 tick 增至 **7 tick / 0.35 秒**；玩家间及无可用攻击动画时的近战相杀接触差由 2 tick 增至 **3 tick / 0.15 秒**。

有攻击动画的怪物使用该招真实前摇 **x**：闪光出现在 **x/5**，精准防御窗口为 **[3x/5, x]**，包含真实接触时刻。在窗口内新按 C 可完美格挡；玩家本次攻击首次进入有效帧时，若怪物正向该玩家发起近战，且距离、方向、视线和当前装备合法，则发起相杀。该招在窗口之前进入有效帧，不会因之后继续保持有效状态而补认。相杀使用双方护甲前的真实完整伤害：差值 **≤3 时双方伤害均为 0**，差值 **>3 时只有优势方造成差值减 3 的余伤**。怪物原生攻击只执行一次，已相杀的动作不再于后续动画接触时重复扣血；其它未被相杀的招式按原接触帧造成伤害。

比例时序为 `guard_cues.json` 的默认 `timingMode=windup_fraction`，`flashAtFraction=0.2`、`windowOpenFraction=0.6`；旧五字段文件也采用比例默认，不必改写自定义文件。原素材前摇保留，不为提示强行延长。服务端 20 TPS：闪光向下、窗口起点向上取 tick，量化误差小于 1 tick。显式 `fixed_ticks` 可兼容旧固定提示参数。

成功完美格挡立即清理自身当前动作、排队攻击、后摇和已有硬直。相杀双方立即结束对应动作并清除硬直，不再给相杀劣势方新增硬直；优势方保留完美格挡反击奖励。普通完美格挡仍让被格挡的攻击者僵直 4 tick。延迟到达的旧动作相杀不能终止已经开始的新动作；旧动作优势只授予后续反击机会。

完美格挡后继续按住 C，服务端立即重开一次新的 7 tick 窗口；同一次按住最多触发 **3 次完美格挡，包含第一次**。第三次后继续按住仍遵守普通格挡、体力和连续受压规则，不再刷新完美窗口。松开再按开始新一轮。界面挂起、按住续包、轻重格挡切换及装备恢复不产生新的物理按键，也不重置三次上限。提示攻击在第一次仍要求正确的新按键，成功后的自动重开才可在新窗口内继续精准格挡。

格挡成功只免除受击镜头晃动。服务端确认实际普通格挡伤害后，按对应伤害来源通知客户端，在原版伤害包到达时取消该次镜头 hurt transform；生命值、击退和原版受击计时保持结算。完美格挡和零伤害格挡也会停止之前仍在播放的受击镜头。随后未挡住的攻击恢复正常震屏。同源连续格挡不能把免震屏效果转给下一次未格挡伤害。新增呈现消息后网络协议为 **11**，联机双方须更新同版。

`DefenseFlowMigration` 对已有配置只执行一次：启用的全局及各武器完美窗口加 1，0 保持禁用；相杀窗口加 1（旧文件缺字段时按旧默认 2 升至 3）；启用的提示窗口加 1，必要时提前闪光以覆盖新窗口。其余数值、伤害容差和自定义字段保留。窗口遵守原上界。原文件保存在 `defense-flow-backup-v1/`，先保存完整候选计划再逐文件写入，意外中断重试不会重复增加 tick；完成标记为 `defense-flow-migration-v1.json`。缺失文件按当前默认补齐，不把新默认再增加一次。

西洋剑前三种挥砍使用新的动作与连续速度曲线，修复前摇全程固定在起始帧的问题。肩、肘、腕沿短暂连续蓄力加速，速度峰值位于有效帧，随后自然收势；原第四段刺击与服务端伤害、体力、前后摇tick不变。移动倾斜与最大3°的挥砍反作用按向量合成，并将新增倾斜层限制为5°，通过同一腰部支撑层带动上身，保持腰腿连接。真实同tick多次渲染不重复积分。只更新两份原有rapier模型，未改双刀、长枪或其它素材；官方配置中的未修改原版模型按SHA识别升级，自定义模型保留。资产前后SHA见 `rapier-motion-0.8.4-manifest.json`。

平衡相杀在快捷栏上方显示“相杀 · 双方伤害免除”，与原有格挡音效和粒子共同反馈实际免伤，避免只有未展示的同步消息。
