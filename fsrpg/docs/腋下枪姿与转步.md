# 腋下持枪与转步（0.5.4）

用户要求右肘向后带、枪杆保持在腋下，腰部转向带动骨盆和腿，并通过小幅踏步重新支撑。此轮采用运行时几何求解，没有制作或替换动作素材。

就绪握点以肩部为基准，避免跑步动作把后手抬到肩上。后手保持解剖分支；预备、恢复阶段保持持枪结构，接触阶段仍使用服务器攻击轨迹。身体朝向围绕实际瞄准方向约束，完整枪杆必须避开躯干和头部。碰撞条件优先于舒适度评分；胸部、共同握点和手臂一起求解，保留双手 58 cm 握距及骨长。

前手以掌心定位沿枪杆斜向扶持，后手决定枪轴；不再强迫两只前臂都与枪杆垂直，避免为了前手闭合把右肘压低、后手抬高。大角度俯仰允许肘部斜率自然变化，完整枪杆避碰与关节连续约束仍然保持。

骨盆根据已求解的胸部转向平滑跟随；站立转向时左右脚交替抬起约 5.6 cm，每步最多约 28°，另一只脚保持完整鞋底支撑。行走使用现有步态和实际移动方向。转步状态在同一长枪动作链的招式交接中保留。

腰部皮肤、外套及胸甲在原 UV 上按横截面分段。胸部与肩膀保持原姿态，腰段逐渐转向骨盆，裤腰下缘和两腿顶部使用同一骨盆朝向。股骨上端有短过渡段，避免大腿倾斜时在腰带接缝露出缺口。完整枪杆还避开腰段旋转所覆盖的保守体积。

已有矩形操作宽度 3 倍、高度 2 倍的设置继续保留；消耗配置和已有模型不重新迁移。新增客户端字段只补缺失值：`spearCarryDownCm`、`spearCarryBackCm`、`spearCarrySideCm`、`spearPelvisResponseTicks`、`spearTurnStepTicks`、`spearTurnStepDegrees`、`spearTurnStepLiftCm`。

验证包括普通/纤细模型的静态角点、连续内场/周边、呼吸、行走、侧移、倒退、冲刺、刺扫与恢复；另从实际皮肤变形重建鞋底、髋关节和骨盆。最终发行以 `verification/spear-underarm-turn-20261014/final-report.json` 的同一 JAR 哈希、DISPLAY5 实机录像和完整枪杆审计为准。原先仅检查关节/握点的通过报告不足以证明无穿身，早期失败与用户指出的问题录像保留在同目录。
