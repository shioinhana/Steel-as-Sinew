# 0.9.1：技能树单页 UI 与创造模式修行工具

目标环境：Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21。开发版本 **0.9.1**，网络协议仍为 **12**（快照 JSON 新增字段，无新消息类型）。

本轮只改修行界面与创造模式调试入口，不改战斗数值、技能效果、按键或既有配置默认值。

## 1. 技能树单页 UI

- 打开方式不变：**P**。窗口为居中单面板，左侧固定 4 个分类：**西洋剑 / 双刀 / 弓 / 步法**，点击即切换，不再有图表页码、上下翻页按钮或逐段翻页。
- 中间区域把当前分类的**全部节点一页展示**，并按分支家族归组：
  - 西洋剑：入门 / 刺击 / 蓄力拨挡刺 / 缺血处决。
  - 双刀：入门 / 连击层数上限（三层、四层、五层、试炼六层按成长要求排序）。
  - 弓：入门 / 速射强化（连续引弓、落点预测）/ 狙击镜 / 150 分支（如梭、啮矢）/ 250 分支（岩下电、穿堂风）。
  - 步法：流派（脱兔、飞鸿）/ 登云一至三 / 若轻一至三；每个节点卡显示状态标记（✓ 已学、◆ 创造授予、+ 可学、✦ 自动生效、· 条件不足）。
- 右侧为单一详情面板：状态、描述、条件、前置、互斥、成本/选学额度与操作按钮；内容过长时仅该面板可用滚轮滚动，页面本身不翻页。分类栏、内容区和详情区在 940×520 左右的 GUI 空间内完整可见。
- 顶部统一显示心法/煅体/步法可用点和总值、三项武器成长、试炼/末影龙标记、步法选学额度；分类按钮显示该分类已学/总数。
- 左栏底部保留图例；底部提示当前页无需翻页。列表实现为纯 Java 的 `SkillTreeLayout`，未知的未来节点会进入「其他」组而不是被隐藏。

## 2. 创造模式修行工具（仅 `isCreative()`）

服务端权威，客户端只发意图；非创造模式调用会被服务端拒绝（`仅创造模式可用`）。

- **补满进度**：一键把心法/煅体/步法设为配置可满足的最大值（按当前技能树计算 91 / 102 / 600，可用点=总值），三项武器成长设为各树节点要求最大值（301 / 400 / 300），并置试炼、末影龙标记、步法/心法/煅体训练门为开启，资质效率满；不自动学习任何技能（避免替玩家做选择）。
- **自由学习**：创造模式下点击/右键任意手动节点即可学习，忽略前置、条件、点数成本与步法选学额度；互斥组自动替换旧选择；节点以「创造授予」标记并真实生效（包括作为其它节点前置和技能效果）。再次点击「移除技能」（或右键已学节点）可取消。
- **清空重选**：底部「清空重选」需点两次确认；清空已学技能与创造授予、心法/煅体/步法点数、三项武器成长、双刀层数和训练余量，保留心法/煅体/步法已开启状态（可立即重选且步法 B/G 可用），并保留试炼/末影龙等世界成就标记。

实现上 `SavedProgress` 末尾追加 `creativeNodes` 集合（旧存档/旧 JSON 缺失时按空集恢复，SCHEMA_VERSION 仍为 1），`NodeView` 末尾追加 `creative` 字段，快照顶层追加 `creative` 布尔；已有存档字段与效果不变。

## 3. 兼容与边界

- 普通模式下的学习条件、成本、互斥和自动节点行为不变；本轮的创造工具只在创造模式生效。
- 创造授予“补满进度”不自动学技能；自动节点需先学会对应入门（可用自由学习一键补），随后按条件自动生效。
- 本轮没有新增按键，也没有改动战斗/技能数值；旧 UI 的 `SkillTreeScreen.selected` 与 `rebuild()` 保留，供已有实机剧本继续使用。
- 界面文字沿用中文，图标状态不依赖颜色单一表达。
