# 0.7.5：金闪提示、精准格挡与宽松剑类连段

已有受控近战攻击在接触前出现一次贴在攻击者身上的金色闪光。默认提前 6 tick（0.3 秒），闪光显示 120 毫秒；精准格挡输入接受区间为 `[接触 tick - 6, 接触 tick)`。恰在接触 tick 才按下已经太晚，提前持续按住则走普通格挡。普通格挡的朝向、资源消耗和破防条件仍然生效。

用户已选择先实现可调时序。《绝区零》[官方玩法说明](https://wiki.hoyolab.com/pc/zzz/entry/260?lang=zh-cn)说明金闪与支援时机，但没有公布统一闪光提前量及判定帧数。本版 6 tick / 120 毫秒是项目初始标定，不能当作已验证的原作参数。

## 调整提示和输入窗口

服务端 `config/fsrpg/guard_cues.json`：

```json
{
  "enabled": true,
  "flashLeadTicks": 6,
  "inputWindowTicks": 6,
  "flashDurationMillis": 120,
  "guardCancelsActive": true
}
```

`flashLeadTicks` 决定提前多久提示；`inputWindowTicks` 决定接触前多久接受新按键。两者均以服务端 tick 为单位，20 tick = 1 秒，且 `1 ≤ inputWindowTicks ≤ flashLeadTicks ≤ 60`。窗口不能早于提示，二者不必相等。`flashDurationMillis` 只控制视觉显示，允许 16–500 毫秒。调整后执行 `/fsrpg reload`；重载会取消正在排程的攻击，按住 C 的状态保留，重载不会凭空产生新按键。

素材原前摇短于提前量时，仅以玩家为目标的受控攻击延长前摇至能完整提示；接触仍由同一个服务端时钟提交，原动作曲线在接触前后分别映射。关闭提示时恢复素材配置前摇及既有按键年龄判定。未接入接触时序的远程、法术、爆炸和特殊攻击仍走既有流程，见 [怪物攻击接触时序](怪物攻击接触时序.md)。

一次新按 C 只为当时已开窗的攻击序列各自授权一次，命中时各自消费；后来才开始攻击的另一只怪物不能借用这次按键。释放再按会产生新边沿，持续按住、网络重发、轻重格挡切换、从背包返回或拿出武器都不产生新的精准资格。客户端分别跟踪真实绑定键和当前能否格挡，服务端独立保存按键序列并判定结果。

有效提示窗口内的新 C 可立即进入格挡，包括打断自己的有效攻击帧；取消当前招和缓存下一刀，不返还已花体力、不重置冷却。眩晕、闪避或拔刀等非法状态不能借此绕过。禁用精准格挡的武器/重格挡配置继续禁用。成功后敌人僵直 4 tick，4 tick 内左键反击伤害 ×1.5。

BEGIN 一次传入未来的提示、开窗、关窗、接触时刻；CONTACT、CANCEL 和 END 同序列更新。客户端按世界时间和原生 partial tick 显示一次闪光，重复包不重播，过期包不补播，取消/死亡后不残留。提示只显示给本次目标玩家，位于攻击者胸侧，遮挡、背后、屏外、F1、菜单及旁观视角会隐藏。

## 连段输入

单剑、双刀不再要求踩窄窗口才能续刀。前摇、有效帧、后摇内均可预输入一刀，下一次输入只替换这一格缓存；当前攻击有效帧完整播放并提交后，才开始下一刀。默认跳过剩余后摇，若自定义 `cancels.recoveryAttack=false` 则等整招结束再出缓存招。

单剑继续使用原有四段 `sword_left → rapier_downcut → rapier_crosscut → rapier_light_thrust`。即使完整收招，默认仍保留 12 tick（0.6 秒）段位；下一次点击继续，第四段后循环第一段。`styles.json` 的 `controls.comboResetTicks` 可调整这段收招后宽容时间，省略为 12，0 关闭。

双刀同方向连续点击可以持续交替左右手：左键为 `dual_ll ↔ dual_rl`，右键为 `dual_rr ↔ dual_lr`。第三次同方向不再拒绝，也不再增加旧有同手 3 tick 惩罚。换方向仍可缓存，联动斩保留。每次真实出刀才扣一次体力，缓存不提前扣费；单剑 5、双刀 8，按住鼠标不自动连砍。格挡、闪避、收刀等合法中断会清除缓存，之后不补出幽灵攻击。

本版保留原有源动作及官方 ItemStack 武器渲染，重点重做输入缓存、续段和防御优先规则。既有体力等级公式、长枪和弓消耗不变。

## 配置升级

首次升级只把已启用的 `perfectGuardTicks` 统一为本版 6 tick，原为 0 的禁用项保留；逐字段迁移 `combat.json` 和 `styles.json`，其余字段与文件保留。原文件逐字节备份到 `guard-cue-backup-v1/`，`guard-cue-migration-v1.json` 防止重复迁移，再新增 `guard_cues.json`。官方实例配置清单从 43 个文件变为 47 个，独立暂存验证确认原目录未写入、第二次重载幂等。
