# 0.7.9：单次地面冲量、武器检视与背枪跑姿

目标环境为 Minecraft 1.21.11、NeoForge 21.11.45、Java 21。版本 **0.7.9**，网络协议 **10**，客户端与服务端需要使用相同协议。最终完整构建与 **70 个自定义测试任务**、配置精确复制后的 51→54 文件迁移，以及同一冻结包的单次冲量真实客户端 **6 场景 / 66 项检查**、检视 / 背枪主实机 **18 场景 / 38 项检查**均已通过。最终原生帧、12 种动作及背枪的视觉检查、逐图完整性校验、输出 30 FPS 录像编码、部署预检与正式实例直接安装均已完成；两份实机与实际安装 JAR 的 SHA-256 一致。

## Shift 只设置一次速度

拔刀且落地时，新按原版潜行键（默认 **Shift**）消耗 **5 体力**，向当前输入方向设置一次水平 XZ 速度；没有方向输入时向角色前方。默认初速度为 **27 格/秒，即 1.35 格/tick**，当前 Y 速度保留。随后完全交给原版阻力、重力、移动输入与碰撞处理，没有逐 tick 覆盖移动参数、固定步长或传送。

普通地面、没有后续移动输入时，默认冲量自然衰减后约移动 3 格。冰面、障碍、移动输入和其它原版作用会改变实际距离与耗时；本版不再保证 3 格或 0.5 秒。可在地面冲量后正常跳跃，跳跃与落地继续走原版物理。

**离地不能发起**。客户端使用实际 `onGround` 筛除空中新按，服务端再次校验落地状态，拒绝时不扣体力，也不改变体力回复状态。空中按下后一直保持至落地不会补发，必须松开再按。

长按 Shift 只续接普通 **sprint** 意图，原版实际 WASD 可以继续改向，不将角色固定在触发时的世界向量上，也不另行设置跑速。费用只收一次；松键后新按才尝试下一次付费冲量。原 **Alt 闪避** 的轨迹、费用和无敌规则独立保留，**Shift+C 优先重格挡**。

服务器按物理按下边缘授权一次冲量，并在同次接受中扣费、消费授权和发送只含 XZ 的速度包。客户端按按下编号、序列、实际玩家实体、维度和游戏时钟核对后只应用一次；重包、旧包与生命周期变化不能重复写入速度。普通快速点按即使已经松键，仍可收到已被接受的一次冲量；界面、失焦和格挡中断会取消尚未应用的晚包。

## H 检视：四类武器各三种

用户明确指定使用 **Astra Ultra** 设计本轮动作。在已有骨架、官方物品与握持链上加入 12 种可配置的展示动作，详细动作设计见 [武器检视动作](武器检视动作-0.7.9.md)。

| 武器 | 三种检视 | 默认时长 |
| --- | --- | --- |
| 单手剑 / 西洋剑 | 挽剑花、举刃巡锋、立剑致意 | 5.8 / 5.0 / 4.4 秒 |
| 现有双刀 | 交刃摩擦、双刃轮转、交剑展锋 | 5.6 / 5.4 / 4.6 秒 |
| 长枪 | 双握舞枪、横枪校衡、立枪观镞 | 6.4 / 5.3 / 5.0 秒 |
| 弓，速射与狙击共用 | 指检弓弦、翻弓巡臂、抬弓校线 | 5.0 / 5.4 / 4.7 秒 |

拔刀站定后按 **H** 循环当前武器的三种动作。默认越肩与第三人称可完整显示；第一人称不套用第三人称坐标，按 H 会提示切换越肩或第三人称。原自动检视保留，默认连续站定 **10–30 秒**后触发，使用同一动作目录。

检视属于本地展示，不发送伤害、技能或资源请求。移动、攻击、格挡、受击及其它实际战斗状态优先中断，不能让检视挡住真实操作。原始玩家模型与旧攻击动作源文件保留，手持物仍使用实际 ItemStack 的官方渲染。

## 旧双刀与弓的腰口连接

旧双刀与弓导入骨架的躯干中心、枢轴和缩放，与原版皮肤固定长度的 12 像素躯干不同。此前直接把源骨架变换用于人物模型时，实际躯干下沿可能没有落在双腿髋部中心，检视或普通动作会显出腰口脱离。

`LegacyWaistFit` 根据实际原版躯干下沿与双腿髋部中心求出差值，再对上身各根节点施加同一个公共平移。头、手臂与官方物品链随上身一起移动，腿部和原有支撑仍在原处；源关节旋转、缩放、骨长和原始动作曲线不改写。`LegacyWaistFitTest` 已纳入并通过本版 70 项自定义任务；最终客户端同时检查了实际皮肤腰口，目视核对的双刀原图也保持腰口连接。

## 长枪快跑改为右手背枪

地面实际快跑时，枪放到背部，由右手握住，左手释放枪杆并跟随跑步摆动；普通行走继续双手持枪。进入背枪默认约 **0.2 秒**，停止后约 **0.15 秒**回到双手普通持枪；攻击开始立即回到双手握持，避免出招时还停留在背枪姿势。

快跑判定同时要求真实 sprint、落地和实际水平位移；原地按跑键不切换背枪。空中继续使用既有离地姿势保持，不因下落凭空换成格挡。

还修复了背枪期间改变瞄准、随后停止时的衔接：此前保留的普通握枪目标可能过期，约 0.15 秒回收结束后才切到新目标，枪与手会在末帧跳一下。现在回收期间持续求解、刷新最新双手目标，并按回收权重平滑接回，避免结束时突然追赶瞄准。进入与完整背枪阶段由背枪动作接管双手，满权重跳过正常双手 IK；攻击仍按真实战斗状态立即恢复双握。


## 配置与字段迁移

`config/fsrpg/combat.json` 的 `burstDash` 增加：

```json
"initialSpeed": 27.0
```

单位为格/秒，合法范围为 0.1–80；接受时除以 20，只设置一次水平速度。旧 `distance`、`durationTicks` 与 `runSpeed` 的原值兼容保留，不再强制位移曲线或跑速。费用、冷却和输入租约继续由 `staminaCost`、`cooldownTicks`、`inputLeaseTicks` 配置；默认分别为 5、10 tick、12 tick。

旧配置缺少 `initialSpeed` 时，首次按 `clamp(distance × 9, 0.1, 80)` 补齐，默认旧距离 3 对应 27。迁移只补缺失字段，所有已有值保留；原始字节备份到 `ground-impulse-backup-v1/combat.json`，完成标记为 `ground-impulse-migration-v1.json`，重复启动不重复迁移。

`config/fsrpg/weapon_inspections.json` 首次按发行资源种子创建，已有自定义文件不覆盖。动作目录包含 ID、武器类别、名称、时长、进出时长与关键姿态；读取失败保留上一份已校验目录。现有客户端 TOML 的 `idleInspections`、`idleInspectionMinSeconds` 和 `idleInspectionMaxSeconds` 继续控制自动检视与等待时间，已有自定义设置不因本版被重置。

官方 0.7.8 的 51 个 FSRPG 配置文件已精确复制到隔离 stage，并验证迁移为 54 个：只新增一次冲量标记、原始 combat 备份与检视目录种子；原 `combat.json` 只增加缺失的初速度字段，其它已有文件和字段保持不变，第二次重载字节幂等。正式实例源配置在 staging 期间保持原样；部署后已核对为 54 个配置文件，既有字段、其它 Mod、用户存档和客户端 TOML 保留，原有武器功能延续。
