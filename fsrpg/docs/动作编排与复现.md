# 动作编排与复现

战斗判定时间保存在 `config/fsrpg/skills.json`，单位为 tick（20 tick/秒）；可见动作保存在 `config/fsrpg/models/*.fsvoxel`，单位为秒。修改判定时间后，前摇、有效段、后摇各自重映射到动作的事件标记，不需要重新画整套动作。

## 本次动作设计

双刀左键固定左手左斩 `dual_ll`，右键固定右手右斩 `dual_rr`。点按一次一刀，按住不自动挥砍，同侧可重复，最多缓存下一刀。左右单刀使用镜像轨迹：从髋侧低持刀姿抬臂蓄势，腰肩带动上臂，小臂逐渐展开，沿较宽的斜下弧挥过目标；另一只手配合回收。穿过目标后保留余势，再收回双手低持刀的 `dual_idle_00`。旧 `dual_rl`、`dual_lr` 保留命令与配置兼容。

双刀的剑柄中心与拳心固定，采用50°斜握；切面由肩部与有限的前臂旋前共同调整。大小臂长度固定，肘按正确方向屈曲，手腕保持中立；前臂旋前沿表面逐渐分布，避免扭转集中在肘部。客户端在前摇前40%以内完成姿态过渡，保留蓄势过程，并呈现支撑手的配合动作。皮肤、盔甲及实际 ItemStack 仍走原版渲染。开发快速姿态预览使用 `tools/run-weapon-review.ps1 -World "复制测试世界名" -Suite pose`，同时输出正、背、斜侧及握柄近景，检查默认背后视角的整体轮廓；它不代替后续动态检验。

检查指定动作可追加 `-PoseSamples "tools/pose-samples-dual-cuts.json"`。此文件用 `action`、`seconds` 指定动作及采样秒数，`profiles` 中0/1为普通/细臂皮肤、2/3为对应钻石盔甲；`views` 可选 `front`、`back`、`oblique`、`back-grip-close`。总数最多64张。随附计划采样四刀的0.23/0.30/0.40/0.57秒，检查蓄势、入刃、中段、穿过目标的姿态；输出清单记录实际模型、JAR和计划文件的SHA256。

长枪保留左手在前、右手在后的58cm双手间距。刺击先收枪，侧身姿态保持到出枪阶段，后手推动枪杆，前手导向；身体只提供适量前倾和重心转移。扫击的方向严格来自服务器接受的鼠标轨迹，准备与收势负责转腰和稳住枪杆。

西洋剑使用独立的握柄倾角，区分蓄力与刺出，限制腕部摆动并由肩肘共同送剑；奔跑竖剑通过肩部带动整条手臂，保持肘腕关系。五连、格挡、检视与拔收刀使用同一握柄定义。

移动按照实际位移驱动脚步，保留方向倾斜、头部跟随和腰髋偏移；上半身攻击与下半身移动分层。髋根固定在骨盆下，前后脚由脚底目标与膝部求解形成，鞋底在承重时保持水平。旧模型中的腿部位置偏移作为脚的站位意图读取。静止呼吸使用连续时钟，双刀肘肩有轻微随动，不在每次攻击或收招时重新开始吸气。

## 编辑和重新导出

已有0.3.0安装升级时，替换FSRPG JAR，并备份后更新 `config/fsrpg/models/` 中的 `rapier.fsvoxel`、`dual_blade.fsvoxel`、`spear.fsvoxel`。模型已经存在时不会被JAR内默认资源自动覆盖。保留自行调整过的任务与技能JSON；本次编舞修订不要求重置任务进度或战斗数值。本机开发客户端的三份模型已经同步，旧模型保留为 `.pre-choreography-031.bak`。

`tools/weapon-choreography.json` 是双刀与长枪的编舞源参数：`dualLeadArc` 定义左右单刀的镜像曲线，`dualFollowArc` 保留旧交叉斩曲线，另含持刀姿态与长枪收放轨迹，列名和单位写在文件开头。`tools/author-weapons.mjs` 读取它，以60Hz采样，经 Workbench 的建模、命令、保存和导出接口生成模型。西洋剑由 `tools/author-rapier.mjs` 制作。

JSON 中动作时间0.30与0.57分别对应有效段开始、结束。双刀用 `palmX/Y/Z` 直接定义握柄弧，`elbowHintX/Y/Z` 指定肘部弯曲方向的参考；向右斩时镜像横向坐标。左右单刀均从中立低持刀姿开始并收回，可单独修改蓄势、出刃和收刀，默认服务端4 / 3 / 7 tick不变。修改后用随附工作台运行作者脚本，再把导出的模型复制到实际客户端 `config/fsrpg/models/`；运行中的游戏使用 K 窗口重载模型。直接编辑 `.fsvoxel` 也可生效；再次执行作者脚本会以编舞源重新生成模型，因此应保存手工改动的副本。

源码构建运行 `gradlew.bat build`。实机验证使用复制世界和精确发布JAR，动态录像从每个真实 `RenderFrameEvent.Post` 采集。普通/细臂皮肤、盔甲与前后视角使用独立静态姿态检阅；静态图片不计入动态帧率证据。本次双刀重制的验证目录为 `verification/dual-remake-20261008/`，构建、左右输入与挥砍实机检查已通过；完整下肢审计仍有脚步方向告警，详见该目录内 game/independent-motion-review.json。

同步包的版本号包含阶段变化，并不等于新攻击。客户端保留同次攻击的连续时钟，只在真正的新动作上建立过渡；新招提前到达时先呈现当前有效段尾端，随后接入最新服务器进度。前摇可取消、有效段锁定、后摇可跳过与提前缓存下一招的规则不变。

攻击、呼吸与检视共用客户端逐渲染帧累计的表现时钟，暂停时停止、切换世界时重置。服务器校正世界时间不会让动作倒退或重置检视等待。检视实机检查额外记录客户端tick与墙钟时间，以确认默认10～30秒静止等待确实经过。
