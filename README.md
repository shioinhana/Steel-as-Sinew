## 安装与开发启动

客户端 `mods/` 使用 `fsrpg-neoforge-0.9.1.jar` 与随附的 `fsvoxel-renderer-neoforge-0.6.0.jar`；升级时备份并移走旧 FSRPG JAR。服务端安装 FSRPG，FSVOXEL 为客户端依赖。两端需要相同协议版本的 FSRPG 才能同步战斗、修行和任务数据，0.9.1 仍使用协议 12（仅快照 JSON 增加创造模式字段，无新消息类型）。

源码使用 Gradle Wrapper 9.5.0、ModDevGradle 2.0.144 和 Java 21 工具链。`Build.cmd` 构建，`Run-Client.cmd` 启动开发客户端；也可执行：

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
.\gradlew.bat runServer
```

开发游戏窗口必须位于 Windows `\\.\DISPLAY5`，监视器启动 agent 不进入发行 JAR。实机测试只使用复制世界。完整构建和验证通过后，直接部署到 `C:/Users/34003/AppData/Roaming/.minecraft/versions/1.21.11-NeoForge/mods/`，保留其它 Mod、用户世界和自定义配置，并核对部署 JAR 的 SHA-256。部署规则见 [AGENTS.md](AGENTS.md)。

### 双刀

主副手各装备一把剑。默认 `styles.json` 使用 `controls.mode: "legacy_dual"`：左右键表示挥斩方向。连续左键依次使用左手左斩 `dual_ll`、右手左斩 `dual_rl`；连续右键依次使用右手右斩 `dual_rr`、左手右斩 `dual_lr`。同向两刀后两手均在该方向末端，第三次同向输入拒绝，也不能缓存第三刀；等待完整收招回到默认位置后可重新起手，或用反向斩真实改变对应手的位置。当前有效帧完整结束后才出下一刀，不额外增加同手延迟；点按一次一刀，按住不会自动近战连砍。

同时按下左右键使用 `dual_combined` 联动斩，默认冷却 100 tick，并将两手位置归中；连续 40 tick 无攻击也归中。原有 `controls.mode: "dual"` 继续保留，供自定义配置使用固定左键左手、右键右手的操作。

持刀移动加成 +15%；挥砍时另减 35%。解锁连击节点后，每次真实命中加一层，每层挥砍移动另加 15%，这些数值按加法叠加；100 tick 没有真实命中掉一层。成长和试炼分别将上限提高到 3 / 4 / 5 / 6 层，空挥不计成长。

0.7.7 的 READY 回到作者的 `static_idle`，移动时读取原 `walk_hold` / `run_hold`，循环按各片段原时长取模。攻击结束后不再把手臂停在 `dual_idle_XX` 中烘入的旧攻击末帧。源动作文件保留，旧别名仍可供兼容配置引用。

0.7.8 将双刀左右肩根各向外微调 **1.5625 cm**，约为原版模型的 0.25 像素；标准 / 纤细皮肤与盔甲、前臂、手和官方物品链共用该根部位移。攻击曲线、关节旋转、骨长及手内握点保持原样。

0.7.9 增加 `LegacyWaistFit`：旧双刀与弓的导入躯干枢轴 / 缩放与原版固定 12 像素躯干不一致时，按实际原版腰口和双腿髋部中心求一个公共平移，只移动上身根节点，头、手臂和物品链一起跟随。腿部、关节旋转与源动作曲线保持原样，避免检视或普通动作时腰口脱离。

### 弓

学会弓术后，默认档位为速射；R 拔刀 / 收刀，V 选择速射 / 狙击档位。右键按住蓄力、松开射箭；默认完整引弓分别为 10 / 30 tick。左键点按为近战撞击。弓术 50 分后，速射模式可按住左键自动连续引弓；100 分显示狙击落点预测；300 分解锁狙击镜，最高 8 倍。

150 分在 P 技能树中选择“如梭”或“啮矢”，250 分选择“岩下电”或“穿堂风”；每一组只能选择一种。具体效果、基础属性条件与默认参数见 [旧版技能迁移](docs/旧版技能迁移.md)。射箭使用真实箭矢、弹药与耐久，由服务器判断能否发射。

### 长枪

点刺 `spear_thrust` 保留 **1 / 1 / 2 tick** 的前摇 / 有效 / 后摇，普通点按合计 **0.2 秒**，先预扣体力 **10**，实际空挥结束退回 **5**。0.7.7 默认 READY 比既有腋下握持位置额外回收 **14 cm**；按下左键即刺出，长按停在伸出姿态，松开后收回。长按期间移动准星会连续判定枪尖扫过的区域，同一挥刺最多接触每个目标一次，保持与拖动不会反复出新枪或重复扣费。保持输入失去续约、角色受打断、死亡或换下武器时取消保持。

大幅转身时，身体转向包可能先于新准星轨迹抵达服务器；此时暂停旧方向的伤害判定，把画面枪向限制在当前前方范围内，保留原保持租约，收到新的合法轨迹后继续。暂停期间不补扫已失效的旧区域。极快连续拖动时，所有轨迹段与移动起点共用每碰撞 tick 最多 4096 条射线预算，并以保守覆盖余量处理采样间隔。

0.7.8 的拖动扫中目标后，击退方向取命中处准星轨迹的切向，默认强度为该技能击退量的 **50%**，仍受目标击退抗性和事件取消影响。地面目标不接受向下冲量，纯下扫没有位移效果；斜下扫保留水平分量。空中目标可沿下扫方向击坠。静止点刺继续沿用原点刺击退。

长枪实机求解继续在固定预算中跟踪上一可行握姿，必要时用解析可行弧和有限胸向候选修复连续性；皮肤、盔甲和物品共用同一姿态缓存，动态握距与完整枪杆避碰继续保留。固定预算求解记录见 [0.7.3 版本说明](docs/release-0.7.3.md)，当前操作与体力规则见 [0.7.7 版本说明](docs/release-0.7.7.md)。

0.8.5 长枪显示浮动准星，不显示限位框，也不再索敌。系统鼠标仍隐藏，完整屏幕输入映射到实际左右各31.5°、上下各28°的枪姿范围；相机俯仰±24°。准星偏离中心的距离驱动平滑转速，靠近身体限位时加速转向，转向消耗偏移使准星逐渐回中。准星和攻击使用同一条考虑镜头视差的世界射线；近处合法目标保持真实伤害方向，仅动画深度延长至前向至少4.5格。服务端仍验证前方轨迹；原有手臂限位、动态握距、胸腰及腿部跟随保留。

长枪装备原版 1.21.11 长矛，唯一状态自动拔刀；右后方越肩浮动准星点按或保持刺击，准星偏移控制渐进转向并更新保持期间的扫击轨迹。0.5.2 时代的“按住拖动、松开扫击”已由 0.7.7 的保持期间即时扫区判定替代。左手握中段、右手握后端。0.5.2 让原有呼吸、行走、侧移、跑姿和刺扫位移先形成完整动作，随后在固定握距上叠加真实枪轴和关节限位；0.6.1 起沿用动态握距。READY 在前方保留固定修正锚点，极端方向携带上一实际可行握点继续原动作；攻击各阶段保持固定锚点，连续性跟随原动作变化，避免动作每帧被拉回静态持枪姿态。保留默认正向肘曲 10–135°、优先腕转 120°、硬腕转 150°、避碰余量 1.5 cm、颈部偏航 85°与侧倾 18°；极端俯仰允许小幅侧倾，头部逐步过渡。0.8.2 快跑与普通行走均使用原有身前双手持枪；专用背枪与斜背覆盖已移除。避碰仍采用评分，极端姿态可能局部贴身。历史操作参数见 [双刀与长枪](docs/双刀与长枪.md)，0.5.1 约束研究见 [长枪动作求解](docs/长枪动作求解.md)，融合与验收记录见 [动作系统融合](docs/动作系统融合.md)。

### 体力回复与空挥结算

0 级基础回复仍为 5 点/秒，等级公式沿用 0.7.4。未处于战斗计时内时满额回复；真实攻击接触、受击以及防御/闪避等战斗活动将默认 60 tick（3 秒）的战斗计时刷新，期间持续回复基础值的 50%，计时结束恢复满额。移动本身不降低体力回复，准备攻击或空挥也不会新开战斗计时；若本来仍在战斗计时内，空挥保持已有半速状态。

发招仍要求能支付原完整费用，并在接受时预扣。进入有效攻击阶段后完全没有接触目标，结束时返还一半；命中、被格挡、被招架或互相拼刀等有效接触保留全额费用。未发出的前摇被取消不享受空挥折扣。弓箭在飞行中仍可能命中，需等撞墙、消失或移除等飞行终结后才结算未命中的返还，松弦不会立即退费。未拉满的有效箭先按既有 70% 费用计算，最终未命中再适用一半费用。

### 滞空动作

普通跳跃和下落继续保留离地时实际提交的基础姿势，不自动替换为 jump / fall 守势或格挡。0.8.0 在此基础上按实际模拟位移的速度、加速度叠加细小的身体与腿部响应：身体俯仰最多 3°、侧倾 1.6°，腿部俯仰最多 4°、侧倾 1.5°；上升、下落与方向变化自然带动晃动，未加入周期循环。已发出的攻击继续上身原稿、保持离地下肢基础，并只使用 25% 附加惯性；腰口与真实握持链共同连接。空中主动 C 格挡也保留起跳下肢并把当前格挡上身接回同一腰口，避免切回地面姿态造成腰部脱离；格挡、受击、闪避等实际状态将这层惯性归零，落地清零并恢复自然移动；游泳、滑翔、骑乘不套用。客户端 `config/fsrpg-client.toml` 的 `airInertiaStrength` 范围 0–1、默认 1，设为 0 恢复离地基础姿势的精确保持。这是越肩/第三人称人物显示层，不改角色速度、重力、伤害或体力；第一人称本轮未新增专用惯性稿。

## 常驻 HUD 与收集任务

生命、经验在快捷栏左侧，灵力、体力在右侧，使用用户提供的四套横条素材。原生快捷栏、副手、护甲、饥饿和氧气继续由游戏绘制；四条在收刀、拔刀、创造模式以及背包或任务窗口后常驻，旁观和 F1 时隐藏。生命与经验读原版数据，灵力与体力读服务端同步值。客户端 `materialHud=false` 可恢复原生生命 / 经验条，详见 [素材 HUD](docs/素材HUD.md)。0.7.0 已接入用户提供的生物动作素材。

首次猎杀怪物后，生物图鉴按种类一次性提交所有常规非装备掉落物各 1 个，奖励各 2 个；累计 5 种送铁剑、镐、斧、锹、锄，10 种送整套铁盔甲。默认收录 63 种有有效掉落物的生物。

作物每种提交种子 1 个、成熟作物 10 个；同物品合计扣 11 个。每种提交后，选择其它作物的种子 5 个并领取骨头 3 个；累计 10 种自动获得全部 22 种可种植作物的种子各 1 个。待选奖励保存在世界中。材料不足、重复提交或奖励背包空间不足时不扣除材料。详见 [收集任务与部署](docs/收集任务与部署.md)。

## 服务端战斗与动画

服务器处理距离、方向、视线、有效帧、资源消耗与每次挥击的目标去重。前后摇不造成伤害；缓存输入在实际启动下一招时扣资源。一般技能冷却从接受施放时开始，特殊突刺从提交刺击时开始。死亡、收刀和强制状态会终止蓄力或攻击。

轻重格挡、弹刀、碰撞闪避和完美格挡反弹原版箭矢沿用现有规则。0.7.3 完美格挡默认窗口为 2 tick；成功后攻击者硬直 4 tick，怪物暂停 AI、移动和近战，结束后恢复。成功后的 4 tick 内，下一次被接受的左键攻击获得 1.5 倍普通攻击伤害；受击、闪避、收刀或换档会清除反击机会。PvP 继续遵守原版服务器规则。

旧武器第一 / 第三人称动作转换为现有 FSVOXEL 文件，继续使用官方玩家皮肤、盔甲和实际物品模型、资源包变换与附魔光效。已有 0.4 模型仍随包保留，外部自定义模型不会被替换。长枪保留动作文件，当前使用浮动准星操作；0.5.2 融合原动作与运行时两手 IK，沿用已有求解配置。0.7.0 额外接入生物原始动作，玩家武器动作继续沿用现有配置。动作与数值迁移来源、兼容规则见 [旧版技能迁移](docs/旧版技能迁移.md)。
