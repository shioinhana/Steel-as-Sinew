## 安装与开发启动

客户端 `mods/` 使用 `fsrpg-neoforge-0.7.9.jar` 与随附的 `fsvoxel-renderer-neoforge-0.6.0.jar`；升级时备份并移走旧 FSRPG JAR。服务端安装 FSRPG，FSVOXEL 为客户端依赖。两端需要相同协议版本的 FSRPG 才能同步战斗、修行和任务数据，0.7.9 使用协议 10。

源码使用 Gradle Wrapper 9.5.0、ModDevGradle 2.0.144 和 Java 21 工具链。`Build.cmd` 构建，`Run-Client.cmd` 启动开发客户端；也可执行：

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
.\gradlew.bat runServer
```

开发游戏窗口必须位于 Windows `\\.\DISPLAY5`，监视器启动 agent 不进入发行 JAR。实机测试只使用复制世界。完整构建和验证通过后，直接部署到 `C:/Users/34003/AppData/Roaming/.minecraft/versions/1.21.11-NeoForge/mods/`，保留其它 Mod、用户世界和自定义配置，并核对部署 JAR 的 SHA-256。部署规则见 [AGENTS.md](AGENTS.md)。

按键均可在 Minecraft 设置中修改，Shift 沿用原版潜行键绑定。`config/fsrpg-client.toml` 的 `thirdPersonWhenDrawn` 控制拔刀后过肩镜头，镜头进出默认 0.5 秒，返回完成后恢复此前视角。普通物品的 R 镜头仅是本地探索视角，不建立战斗拔刀、索敌或攻击状态。

非长枪武器在拔刀后，攻击准星明确指向的生物才尝试建立锁定，默认距离 10 格。服务器校验目标 ID、UUID、距离、实际眼睛射线、方块遮挡和攻击是否被接受；准星没有合法目标时仍可向当前方向出招，不自动寻找附近目标。默认可明确选择普通生物；盟友、已驯服宠物及玩家不作为该选中入口的目标。已有锁定不会被更近敌人或新的准星目标抢走；死亡、越界或失去合法视线时解锁。锁定后角色面向目标，鼠标仅转镜头；未锁定时角色跟随当前鼠标镜头方向，避免使用上一帧角度。

Shift 只有地面新按才发起一次冲量：沿当前输入方向（无输入时向前）设置 XZ 速度，保留当前 Y；默认 `burstDash.initialSpeed=27` 格/秒，即 1.35 格/tick。之后不再逐 tick 写速度、强制位移或传送，实际距离随地面摩擦、真实输入和碰撞变化。普通地面无输入时默认约滑出 3 格，不能将它理解为固定 3 格 / 0.5 秒。可在接受冲量后继续正常跳跃，空中按下不扣费，按住落地也不补发，必须松开重按。长按续跑仅请求原版 sprint，方向和速度由 WASD、原版属性及物理决定；旧 `distance`、`durationTicks`、`runSpeed` 仅兼容保留，不再控制本版轨迹。原 Alt 闪避继续使用自己的资源和判定规则。

H 在当前武器的三种检视间循环；原自动检视保留，默认连续站定 10–30 秒后触发。攻击、格挡、移动、受击与其它实际战斗状态优先中断，检视不发攻击或扣资源。动作参数位于 `config/fsrpg/weapon_inspections.json`，四类武器与关键姿态见 [检视设计稿](docs/武器检视动作-0.7.9.md)。

长枪仅在真实地面快跑时切换为背部单手持枪：右手握住背后的枪杆，左臂跟随跑步摆动。默认进入约 0.2 秒、停止后约 0.15 秒恢复普通双手握枪；攻击开始立即恢复双握，普通行走保持双握。 背枪期间改变瞄准后，停止回收时持续刷新正常双手目标并平滑衔接，避免回收结束才突然跳到新目标；背枪满权重不运行正常双手 IK。

### 西洋剑

西洋剑使用最早 ActionCombat 0.1.1 的静态持剑与攻击上半身；0.7.1 恢复源姿态，去掉后来增加的额外上身倾斜/预备/移动扭转。下身独立采用长枪支撑、方向步态与转步，剑步幅上限 `.55`，保留自然比例和共同垂直支撑位移；上胸、手与武器维持源动作关系。旧版融合记录保留在 [动作限位与剑融合](docs/动作限位与剑融合.md)。

0.7.7 为单剑和长枪共用转步加入额外腰扭上限：身体转向时下身先直接跟随 35%，其余用交替踏步追随；站姿之外的滞后超过 45°时，当帧直接带动骨盆与双脚并开始踏步。单剑原有侧身分配保持原样；45°约束指相对该站姿的额外滞后。

左键依次使用旧版四段：`sword_left → rapier_downcut → rapier_crosscut → rapier_light_thrust`。每次点击衔接一段；前摇和有效帧内的点击缓存下一刀，当前有效帧完整结束后接出，默认可跳过后摇；未续招时正常收招。完整收招后默认保留 12 tick（0.6 秒）段位，再点击继续下一段，第四段后回到第一段。`styles.json` 的 `controls.comboResetTicks` 可调整这段宽容时间，0 表示收招后不保留段位。第五段 `rapier_wrist_rise` 及原有条件还击 ID 仍保留为兼容配置条目，默认四连不包含第五段。

0.7.8 撤掉单剑攻击换段时先显示新动作默认帧、下一帧又叠回上一刀姿态的偏移桥接。下一段直接按对应原稿与既有接触时间映射播放，伤害有效帧和宽松预输入规则保持原样。

右键突刺先解锁“刺击”：西洋剑成长 80 分、心法 30、煅体 25、步法 40。普通突刺默认前摇 / 有效 / 后摇为 **7 / 2 / 2 tick**，伤害 9，距离 4 格，提交刺击时开始 20 tick 冷却；前摇取消不会产生该冷却。

成长 180 分并满足对应基础条件后解锁蓄力拨挡刺：按住右键可持续蓄力，16 tick 蓄满；未满蓄受到攻击会免除本次伤害并立即蓄满，满蓄再受攻击则破防并进入 200 tick 冷却。拨挡后释放伤害 18，不触发普通突刺冷却。刺击提交时沿三维视线方向获得 6 米/秒推进。成长 301 分、满足高阶基础条件并实际击杀末影龙后，突刺命中追加目标缺失生命的 10% 伤害。

这些数值由 `skill_trees.json` 的 `rules.rapier` 决定，修改 `skills.json` 的同名突刺时序、伤害或距离不会覆盖该规则；资源消耗、动作与其它技能仍从技能定义读取。

### 双刀

主副手各装备一把剑。默认 `styles.json` 使用 `controls.mode: "legacy_dual"`：左右键表示挥斩方向。连续左键交替使用左手左斩 `dual_ll`、右手左斩 `dual_rl`；连续右键交替使用右手右斩 `dual_rr`、左手右斩 `dual_lr`。第三次及后续同方向输入可继续出刀，换方向也可预输入；当前有效帧完整结束后才出下一刀，不再因同手连续使用额外增加 3 tick。点按一次一刀，按住不会自动近战连砍。

同时按下左右键使用 `dual_combined` 联动斩，默认冷却 100 tick，并将两手位置归中；连续 40 tick 无攻击也归中。原有 `controls.mode: "dual"` 继续保留，供自定义配置使用固定左键左手、右键右手的操作。

持刀移动加成 +15%；挥砍时另减 35%。解锁连击节点后，每次真实命中加一层，每层挥砍移动另加 15%，这些数值按加法叠加；100 tick 没有真实命中掉一层。成长和试炼分别将上限提高到 3 / 4 / 5 / 6 层，空挥不计成长。

0.7.7 的 READY 回到作者的 `static_idle`，移动时读取原 `walk_hold` / `run_hold`，循环按各片段原时长取模。攻击结束后不再把手臂停在 `dual_idle_XX` 中烘入的旧攻击末帧。源动作文件保留，旧别名仍可供兼容配置引用。

0.7.8 将双刀左右肩根各向外微调 **1.5625 cm**，约为原版模型的 0.25 像素；标准 / 纤细皮肤与盔甲、前臂、手和官方物品链共用该根部位移。攻击曲线、关节旋转、骨长及手内握点保持原样。

0.7.9 增加 `LegacyWaistFit`：旧双刀与弓的导入躯干枢轴 / 缩放与原版固定 12 像素躯干不一致时，按实际原版腰口和双腿髋部中心求一个公共平移，只移动上身根节点，头、手臂和物品链一起跟随。腿部、关节旋转与源动作曲线保持原样，避免检视或普通动作时腰口脱离。

### 弓

学会弓术后，默认档位为速射；R 拔刀 / 收刀，V 选择速射 / 狙击档位。右键按住蓄力、松开射箭；默认完整引弓分别为 10 / 30 tick。左键点按为近战撞击。弓术 50 分后，速射模式可按住左键自动连续引弓；100 分显示狙击落点预测；300 分解锁狙击镜，最高 8 倍。

150 分在 P 技能树中选择“如梭”或“啮矢”，250 分选择“岩下电”或“穿堂风”；每一组只能选择一种。具体效果、基础属性条件与默认参数见 [旧版技能迁移](docs/旧版技能迁移.md)。射箭使用真实箭矢、弹药与耐久，由服务器判断能否发射。

### 长枪

点刺 `spear_thrust` 保留 **1 / 1 / 2 tick** 的前摇 / 有效 / 后摇，普通点按合计 **0.2 秒**，先预扣体力 **10**，实际空挥结束退回 **5**。0.7.7 默认 READY 比既有腋下握持位置额外回收 **14 cm**；按下左键即刺出，长按停在伸出姿态，松开后收回。长按期间移动准星会连续判定枪尖扫过的区域，同一挥刺最多接触每个目标一次，保持与拖动不会反复出新枪或重复扣费。保持输入失去续约、角色受打断、死亡或换下武器时取消保持。

大幅转身时，身体转向包可能先于新准星轨迹抵达服务器；此时暂停旧方向的伤害判定，把画面枪向限制在当前前方范围内，保留原保持租约，收到新的合法轨迹后继续。暂停期间不补扫已失效的旧区域。极快连续拖动时，所有轨迹段与移动起点共用每碰撞 tick 最多 4096 条射线预算，并以保守覆盖余量处理采样间隔。

0.7.8 的拖动扫中目标后，击退方向取命中处准星轨迹的切向，默认强度为该技能击退量的 **50%**，仍受目标击退抗性和事件取消影响。地面目标不接受向下冲量，纯下扫没有位移效果；斜下扫保留水平分量。空中目标可沿下扫方向击坠。静止点刺继续沿用原点刺击退。

长枪实机求解继续在固定预算中跟踪上一可行握姿，必要时用解析可行弧和有限胸向候选修复连续性；皮肤、盔甲和物品共用同一姿态缓存，动态握距与完整枪杆避碰继续保留。固定预算求解记录见 [0.7.3 版本说明](docs/release-0.7.3.md)，当前操作与体力规则见 [0.7.7 版本说明](docs/release-0.7.7.md)。

0.5.3 的可见框、鼠标位置和实际拾取射线共用前方范围：相对身体左右各 45°，绝对俯仰上下各 40°，相机俯仰上下各 24°。现有框配置的屏幕上限运行时横向扩展 3 倍、纵向扩展 2 倍，最多使用视口 96%；实际框尺寸仍随视野角、画面比例、相机俯仰和第三人称视差变化。框内不改变角色朝向，本地身体与该朝向对齐；超出边缘继续移动才转向，服务端拒绝范围外轨迹。胸部在握点求解前限制到前方 89°，保留完整瞄准方向、手臂限位和原动作倾斜。合法近处目标保留真实眼睛到目标的伤害方向，只将动画瞄准深度沿该方向延长至前向至少 4.5 格；角色侧后方的第三人称遮挡不作为目标。近处枪轴仍存在手部与眼睛位置的视觉视差。额外移动倾斜统一限制为 4°。

长枪装备原版 1.21.11 长矛，唯一状态自动拔刀；第三人称矩形内点按或保持刺击，到达边界后继续移动鼠标转向。0.5.2 时代的“按住拖动、松开扫击”已由 0.7.7 的保持期间即时扫区判定替代。左手握中段、右手握后端。0.5.2 让原有呼吸、行走、侧移、跑姿和刺扫位移先形成完整动作，随后在固定握距上叠加真实枪轴和关节限位；0.6.1 起沿用动态握距。READY 在前方保留固定修正锚点，极端方向携带上一实际可行握点继续原动作；攻击各阶段保持固定锚点，连续性跟随原动作变化，避免动作每帧被拉回静态持枪姿态。保留默认正向肘曲 10–135°、优先腕转 120°、硬腕转 150°、避碰余量 1.5 cm、颈部偏航 85°与侧倾 18°；极端俯仰允许小幅侧倾，头部逐步过渡。现有跑姿枪轴仅略向上约 5°，沿用该动作。避碰仍采用评分，极端姿态可能局部贴身。历史操作参数见 [双刀与长枪](docs/双刀与长枪.md)，0.5.1 约束研究见 [长枪动作求解](docs/长枪动作求解.md)，融合与验收记录见 [动作系统融合](docs/动作系统融合.md)。

### 体力回复与空挥结算

0 级基础回复仍为 5 点/秒，等级公式沿用 0.7.4。未处于战斗计时内时满额回复；真实攻击接触、受击以及防御/闪避等战斗活动将默认 60 tick（3 秒）的战斗计时刷新，期间持续回复基础值的 50%，计时结束恢复满额。移动本身不降低体力回复，准备攻击或空挥也不会新开战斗计时；若本来仍在战斗计时内，空挥保持已有半速状态。

发招仍要求能支付原完整费用，并在接受时预扣。进入有效攻击阶段后完全没有接触目标，结束时返还一半；命中、被格挡、被招架或互相拼刀等有效接触保留全额费用。未发出的前摇被取消不享受空挥折扣。弓箭在飞行中仍可能命中，需等撞墙、消失或移除等飞行终结后才结算未命中的返还，松弦不会立即退费。未拉满的有效箭先按既有 70% 费用计算，最终未命中再适用一半费用。

### 滞空动作

所有武器在普通跳跃和下落时保留离地时实际提交的姿态，不自动替换为 jump / fall 守势或格挡。已发出的攻击可继续上半身原稿，下肢保持离地姿态；共同平移将当前腰口接回保留的骨盆，手臂和武器相对上身的动作继续播放。动作结束后保持最后实际呈现的姿态，落地恢复自然移动。主动 C 格挡、受击、闪避等真实状态可以覆盖；游泳、滑翔、骑乘不套用普通滞空保持。

## 常驻 HUD 与收集任务

生命、经验在快捷栏左侧，灵力、体力在右侧，使用用户提供的四套横条素材。原生快捷栏、副手、护甲、饥饿和氧气继续由游戏绘制；四条在收刀、拔刀、创造模式以及背包或任务窗口后常驻，旁观和 F1 时隐藏。生命与经验读原版数据，灵力与体力读服务端同步值。客户端 `materialHud=false` 可恢复原生生命 / 经验条，详见 [素材 HUD](docs/素材HUD.md)。0.7.0 已接入用户提供的生物动作素材。

首次猎杀怪物后，生物图鉴按种类一次性提交所有常规非装备掉落物各 1 个，奖励各 2 个；累计 5 种送铁剑、镐、斧、锹、锄，10 种送整套铁盔甲。默认收录 63 种有有效掉落物的生物。

作物每种提交种子 1 个、成熟作物 10 个；同物品合计扣 11 个。每种提交后，选择其它作物的种子 5 个并领取骨头 3 个；累计 10 种自动获得全部 22 种可种植作物的种子各 1 个。待选奖励保存在世界中。材料不足、重复提交或奖励背包空间不足时不扣除材料。详见 [收集任务与部署](docs/收集任务与部署.md)。

| `weapons.json` | 主副手物品 ID、双持要求、材质倍率，可加入其它 Mod 武器 |
| `combat.json` | 资源、恢复、拔收刀、硬直、闪避、通用防御及西洋剑索敌规则 |
| `collections.json` | 生物掉落与作物目录、提交需求、奖励和里程碑 |
| `quests.json` | 兼容教程任务、前置、目标、奖励与重复规则 |
| `models/*.fsvoxel` | 人体骨架与动作；新版使用 `legacy_rapier`、`legacy_dual_blade`、`legacy_bow` 及各自 `_fp` 文件，旧模型和长枪继续保留 |

`/fsrpg reload` 对整个配置集合校验后原子替换运行定义，失败保留上一份可用配置。弓 50 / 100 / 300 解锁阈值必须在 `skill_trees.json` 和 `archery.json` 中一致。未知字段、无效数值、重复 ID、循环前置和非法引用会被拒绝。技能树基础值是累计总值，学习只扣可用值；ID 应保持稳定。

K 窗口支持动作预览与一般技能数值修改，保存需要服务端管理员权限，并备份 `skills.json.bak`。特殊突刺的权威参数见上表，修改后通过 JSON 重载生效。外部编辑冲突必须先重载再保存。模型在 K 窗口重载；外部模型优先于 JAR 模板，自定义模型文件不被配置迁移覆盖。

世界数据分别位于 `<世界>/data/fsrpg/skill_trees.json`（玩家修行）、`archery.json`（弓技能资源）、`collections.json`（收集）、`quests.json`（旧任务）与 `resources.json`（战斗资源）。玩家数据按 UUID 隔离，移除的稳定 ID 保留在存档。**世界数据文件和 `config/fsrpg/` 的同名定义文件用途不同。**

收集提交保存扣除、奖励和交易回执，重复包不会重复发奖；旧任务页继续保留初次狩猎、技能训练和野外调查。旧任务领奖先保存已领状态再发奖励，仍有保存与交付之间异常终止导致未交付奖励丢失的原有限制。

## 服务端战斗与动画

服务器处理距离、方向、视线、有效帧、资源消耗与每次挥击的目标去重。前后摇不造成伤害；缓存输入在实际启动下一招时扣资源。一般技能冷却从接受施放时开始，特殊突刺从提交刺击时开始。死亡、收刀和强制状态会终止蓄力或攻击。

轻重格挡、弹刀、碰撞闪避和完美格挡反弹原版箭矢沿用现有规则。0.7.3 完美格挡默认窗口为 2 tick；成功后攻击者硬直 4 tick，怪物暂停 AI、移动和近战，结束后恢复。成功后的 4 tick 内，下一次被接受的左键攻击获得 1.5 倍普通攻击伤害；受击、闪避、收刀或换档会清除反击机会。PvP 继续遵守原版服务器规则。

旧武器第一 / 第三人称动作转换为现有 FSVOXEL 文件，继续使用官方玩家皮肤、盔甲和实际物品模型、资源包变换与附魔光效。已有 0.4 模型仍随包保留，外部自定义模型不会被替换。长枪保留动作文件和矩形操作，0.5.2 融合原动作与运行时两手 IK，沿用已有求解配置。0.7.0 额外接入生物原始动作，玩家武器动作继续沿用现有配置。动作与数值迁移来源、兼容规则见 [旧版技能迁移](docs/旧版技能迁移.md)。
