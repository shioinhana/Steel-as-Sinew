# FSRPG 冒险与动作战斗基础模组

Minecraft Java **1.21.11 / NeoForge 21.11.45 / Java 21**，当前开发版本 **0.7.3**。服务端管理战斗判定、资源、修行、任务与奖励；客户端提供常驻 HUD、任务页、技能树、动作预览和武器输入。动画使用独立的 FSVOXEL 依赖，手持物品仍由 Minecraft 官方 ItemStack 渲染。

0.7.3 将长枪实机求解改为固定预算的逐帧局部跟踪，遇到关节跳变时用解析可行弧和有限胸向救援延续握姿；实机腋下持枪路径不再调用旧完整搜索，皮肤、盔甲与手持物共用每个角色本帧的姿态。点刺改为 **1 / 1 / 2 tick，合计 0.2 秒**。单剑攻击体力 5、双刀 8、长枪点刺 10、弓速射 / 狙击 5 / 15；未拉满的有效放箭固定消耗 70%。默认完美格挡窗口 **0.1 秒**，成功后对手硬直 **0.2 秒**，并可在 **0.2 秒内左键反击，普通攻击伤害 ×1.5**。`白色冒险者.bbmodel` 按用户确认替换现有银色冒险者牌外观，保留原物品 ID。完整构建与同一发行 JAR 的 DISPLAY5 实机验收均通过；五个持枪场景的 P99 均改善，官方垂直同步 / 120 FPS / 12 区块设置下压力场景平均 116.99 FPS。极端角度仍可能出现手臂贴身。实现、测量范围、配置迁移与发行 SHA-256 见 [0.7.3 版本说明](docs/release-0.7.3.md)。

0.7.2 优化长枪逐帧握点与避碰搜索：缓存同一手臂候选的碰撞结果、延后计算未入选肘分支的评分，并按原有排序的保守下界排除必败候选；碰撞盒热路径改为直接读取坐标。求解频率、搜索顺序、关节限位、避碰余量与最终握持链保留。体力基础回复由 **1 点/秒提高至 3 点/秒**；旧自定义回复值首次升级乘 3，原文件备份于 `stamina-regen-backup-v1/`，`stamina-regen-migration-v1.json` 阻止重复放大。灵力、回复延迟和消耗保留。实机性能方法与结果见 [长枪性能与体力回复](docs/长枪性能与体力回复.md)。

0.7.1 将默认格挡改为 **C**、重格挡改为 **Shift+C**，E 在拔刀时仍可打开背包。西洋剑上身恢复 0.1.1 原稿与原有 65° 侧身，取消后来叠加的打击倾身、前摇反向姿态和移动摆动；保留接触时间映射。下身使用长枪的支撑、骨盆跟随与转步逻辑，按实际移动方向踏步，皮肤和盔甲腰口保持连接。原始动作文件和官方 ItemStack 握持链保留。

拔刀西洋剑自动在 **10 格内**锁敌，优先敌对生物；没有敌对时可锁普通生物。同优先级保持当前目标，死亡、越界或被方块遮挡时重新选择。盟友、已驯服宠物和玩家不自动入选。角色朝向、攻击与突刺推进由服务端锁方向决定；鼠标独立转动摄像机，WASD 按镜头方向移动，角色保持面对锁定目标。锁敌不改变既有伤害、距离或扇面多目标命中规则。`combat.json` 的 `rapierTargetLock` 控制 `enabled`、`range`、`allowPassive`、`requireLineOfSight`；旧配置只补缺失字段并备份到 `rapier-target-lock-backup-v1/`。专项证据见 `verification/rapier-lock-20261016/`。

0.7.0 仅接入用户指定的五个包：`生命条素材.zip`、`生物动作素材.zip`、`体力条素材x.rar`、`经验条素材.zip`、`灵力条素材.zip`。**F8 打开生物与 HUD 素材图鉴**，可逐项切换生物动作、暂停/重播/循环，并查看全部 28 张 HUD 源图。四条 HUD 继续读取原版生命/经验与服务端灵力/体力数据。原有玩家武器、261001 货币徽章和自定义配置保留；本轮曾混入的其它项目锻造、音效和旧平台已撤出。

30 个生物模型、31 张内嵌纹理、117 段动作按原始骨架与数值曲线转换，27 类原版实体在世界中使用这些外观。AI、生命、攻击和刷新继续沿用原版；防御动作可在图鉴播放，尚无新格挡 AI。原素材未提供 idle/walk 的生物在相应状态保持静态。护甲层、Boss 专用光束/特效与特殊状态仍待适配。劫掠兽源模型含大底板，保留并列为美术返修项。本轮没有接入自然生成或其它项目的场景。

来源与五个压缩包的 SHA-256 见 `artwork/imports/all-assets-manifest.json`；`tools/import-all-art.py` 可从保留的生物/HUD 原文件重建资源。交付目录 `delivery/0.7.0/` 包含设计与素材待补清单。`creatureArtTest` 检查全部动作的 60 Hz FK 与纹理一致性，`build` 运行既有回归；打包客户端验收只使用带标记的复制世界及 DISPLAY5，证据在 `verification/five-packs-20261016/`。

0.6.3 按关节转速放慢双刀 clip 时钟，最大单帧关节步长由 29–69° 降到 14–27°，详见 [双刀笔画时序](docs/双刀笔画时序.md)。0.6.2 让长枪下肢随瞄准俯仰沉降（`spearAimCrouchCm`，默认 6 cm，0 关闭），详见 [长枪瞄准站架](docs/长枪瞄准站架.md)。0.6.1 把握距从固定 58 cm 改为逐帧解算，静止持枪沿用原持握、发力时双手沿杆滑动，详见 [长枪握距](docs/长枪握距.md)。0.6.0 重映射剑类动作的接触时序、让骨盆与双脚跟随侧身站姿、并为相邻动作加入偏移衰减式过渡，详见 [动作时序与体态](docs/动作时序与体态.md)。

0.5.0 将 `actioncombat_legacy_20260923` / 0.1.1 的单剑、双剑、弓术迁入西洋剑、双刀、弓技能树，共 17 个节点。旧存档保留基础武器能力，自定义配置按字段迁移并备份，详见 [旧版技能迁移](docs/旧版技能迁移.md)。0.5.1 改善长枪刚性握持、正向肘曲、避碰与连续分支，其研究记录保留在 [长枪动作求解](docs/长枪动作求解.md)。0.5.2 将这些约束与原有呼吸、步态、移动倾斜和刺扫动作合并，避免求解历史逐帧抵消动作；本轮方法和专项证据见 [动作系统融合](docs/动作系统融合.md)。

## 安装与开发启动

客户端 `mods/` 使用 `fsrpg-neoforge-0.7.3.jar` 与随附的 `fsvoxel-renderer-neoforge-0.6.0.jar`；升级时备份并移走旧 FSRPG JAR。服务端安装 FSRPG，FSVOXEL 为客户端依赖。两端需要 FSRPG 才能同步战斗、修行和任务数据。

源码使用 Gradle Wrapper 9.5.0、ModDevGradle 2.0.144 和 Java 21 工具链。`Build.cmd` 构建，`Run-Client.cmd` 启动开发客户端；也可执行：

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
.\gradlew.bat runServer
```

开发游戏窗口必须位于 Windows `\\.\DISPLAY5`，监视器启动 agent 不进入发行 JAR。实机测试只使用复制世界。完整构建和验证通过后，直接部署到 `C:/Users/34003/AppData/Roaming/.minecraft/versions/1.21.11-NeoForge/mods/`，保留其它 Mod、用户世界和自定义配置，并核对部署 JAR 的 SHA-256。部署规则见 [AGENTS.md](AGENTS.md)。

### 西洋剑

西洋剑使用最早 ActionCombat 0.1.1 的静态持剑与攻击上半身；0.7.1 恢复源姿态，去掉后来增加的额外上身倾斜/预备/移动扭转。下身独立采用长枪支撑、方向步态与转步，剑步幅上限 `.55`，保留自然比例和共同垂直支撑位移；上胸、手与武器维持源动作关系。旧版融合记录保留在 [动作限位与剑融合](docs/动作限位与剑融合.md)。

左键依次使用旧版四段：`sword_left → rapier_downcut → rapier_crosscut → rapier_light_thrust`。每次点击衔接一段，前摇可以取消，有效帧完整结束后可跳过后摇接下一段；未续招时正常收招。第五段 `rapier_wrist_rise` 及原有条件还击 ID 仍保留为兼容配置条目，默认四连不包含第五段。

右键突刺先解锁“刺击”：西洋剑成长 80 分、心法 30、煅体 25、步法 40。普通突刺默认前摇 / 有效 / 后摇为 **7 / 2 / 2 tick**，伤害 9，距离 4 格，提交刺击时开始 20 tick 冷却；前摇取消不会产生该冷却。

成长 180 分并满足对应基础条件后解锁蓄力拨挡刺：按住右键可持续蓄力，16 tick 蓄满；未满蓄受到攻击会免除本次伤害并立即蓄满，满蓄再受攻击则破防并进入 200 tick 冷却。拨挡后释放伤害 18，不触发普通突刺冷却。刺击提交时沿三维视线方向获得 6 米/秒推进。成长 301 分、满足高阶基础条件并实际击杀末影龙后，突刺命中追加目标缺失生命的 10% 伤害。

这些数值由 `skill_trees.json` 的 `rules.rapier` 决定，修改 `skills.json` 的同名突刺时序、伤害或距离不会覆盖该规则；资源消耗、动作与其它技能仍从技能定义读取。

### 双刀

主副手各装备一把剑。默认 `styles.json` 使用 `controls.mode: "legacy_dual"`：左右键表示挥斩方向，出刀手取决于两把刀当前的位置。从归中状态开始，连续两次左键依次使用左手左斩 `dual_ll`、右手左斩 `dual_rl`；连续两次右键依次使用右手右斩 `dual_rr`、左手右斩 `dual_lr`。两把刀都在同一侧时，第三次同方向攻击被拒绝；换方向使刀从另一侧挥回。点按一次一刀，按住不会自动近战连砍。

同时按下左右键使用 `dual_combined` 联动斩，默认冷却 100 tick，并将两手位置归中；连续 40 tick 无攻击也归中。原有 `controls.mode: "dual"` 继续保留，供自定义配置使用固定左键左手、右键右手的操作。

持刀移动加成 +15%；挥砍时另减 35%。解锁连击节点后，每次真实命中加一层，每层挥砍移动另加 15%，这些数值按加法叠加；100 tick 没有真实命中掉一层。成长和试炼分别将上限提高到 3 / 4 / 5 / 6 层，空挥不计成长。

### 弓

学会弓术后，拿出弓默认进入速射，R 切换速射 / 狙击。右键按住蓄力、松开射箭；默认完整引弓分别为 10 / 30 tick。左键点按为近战撞击。弓术 50 分后，速射模式可按住左键自动连续引弓；100 分显示狙击落点预测；300 分解锁狙击镜，最高 8 倍。

150 分在 P 技能树中选择“如梭”或“啮矢”，250 分选择“岩下电”或“穿堂风”；每一组只能选择一种。具体效果、基础属性条件与默认参数见 [旧版技能迁移](docs/旧版技能迁移.md)。射箭使用真实箭矢、弹药与耐久，由服务器判断能否发射。

### 长枪

0.7.3 点刺 `spear_thrust` 的完整前摇 / 有效 / 后摇为 **1 / 1 / 2 tick**，合计 **0.2 秒**，每次消耗体力 **10**。实机路径在固定预算中跟踪上一可行握姿，必要时用解析可行弧和有限胸向候选修复连续性；皮肤、盔甲和物品共用同一姿态缓存，动态握距与完整枪杆避碰继续保留。详见 [0.7.3 版本说明](docs/release-0.7.3.md)。

0.5.3 的可见框、鼠标位置和实际拾取射线共用前方范围：相对身体左右各 45°，绝对俯仰上下各 40°，相机俯仰上下各 24°。现有框配置的屏幕上限运行时横向扩展 3 倍、纵向扩展 2 倍，最多使用视口 96%；实际框尺寸仍随视野角、画面比例、相机俯仰和第三人称视差变化。框内不改变角色朝向，本地身体与该朝向对齐；超出边缘继续移动才转向，服务端拒绝范围外轨迹。胸部在握点求解前限制到前方 89°，保留完整瞄准方向、手臂限位和原动作倾斜。合法近处目标保留真实眼睛到目标的伤害方向，只将动画瞄准深度沿该方向延长至前向至少 4.5 格；角色侧后方的第三人称遮挡不作为目标。近处枪轴仍存在手部与眼睛位置的视觉视差。额外移动倾斜统一限制为 4°。

长枪装备原版 1.21.11 长矛，唯一状态自动拔刀；第三人称矩形内点按瞄准刺击，按住拖动、松开扫击，到达边界后继续移动鼠标转向。左手握中段、右手握后端。0.5.2 让原有呼吸、行走、侧移、跑姿和刺扫位移先形成完整动作，再保持两手间距 58 cm、真实枪轴和关节限位；READY 在前方保留固定修正锚点，极端方向携带上一实际可行握点继续原动作；攻击各阶段保持固定锚点，连续性跟随原动作变化，避免动作每帧被拉回静态持枪姿态。保留默认正向肘曲 10–135°、优先腕转 120°、硬腕转 150°、避碰余量 1.5 cm、颈部偏航 85°与侧倾 18°；极端俯仰允许小幅侧倾，头部逐步过渡。现有跑姿枪轴仅略向上约 5°，沿用该动作。避碰仍采用评分，极端姿态可能局部贴身。操作参数见 [双刀与长枪](docs/双刀与长枪.md)，0.5.1 约束研究见 [长枪动作求解](docs/长枪动作求解.md)，融合与验收记录见 [动作系统融合](docs/动作系统融合.md)。

## 常驻 HUD 与收集任务

生命、经验在快捷栏左侧，灵力、体力在右侧，使用用户提供的四套横条素材。原生快捷栏、副手、护甲、饥饿和氧气继续由游戏绘制；四条在收刀、拔刀、创造模式以及背包或任务窗口后常驻，旁观和 F1 时隐藏。生命与经验读原版数据，灵力与体力读服务端同步值。客户端 `materialHud=false` 可恢复原生生命 / 经验条，详见 [素材 HUD](docs/素材HUD.md)。0.7.0 已接入用户提供的生物动作素材。

首次猎杀怪物后，生物图鉴按种类一次性提交所有常规非装备掉落物各 1 个，奖励各 2 个；累计 5 种送铁剑、镐、斧、锹、锄，10 种送整套铁盔甲。默认收录 63 种有有效掉落物的生物。

作物每种提交种子 1 个、成熟作物 10 个；同物品合计扣 11 个。每种提交后，选择其它作物的种子 5 个并领取骨头 3 个；累计 10 种自动获得全部 22 种可种植作物的种子各 1 个。待选奖励保存在世界中。材料不足、重复提交或奖励背包空间不足时不扣除材料。详见 [收集任务与部署](docs/收集任务与部署.md)。

## 配置与存档

0.5.3 将所有动作的体力消耗降低至此前的 20%，包括技能、闪避、轻重格挡、完美格挡和弓动作。已有配置按稳定 ID 和成本字段迁移一次，保存 `stamina-cost-backup-v1/` 原文件与 `stamina-cost-migration-v1.json` 完成标记；新建配置直接使用降低后的默认值。标记完成后，编辑的成本就是实际服务端扣费，不再次乘 0.2。灵力、资源上限、恢复、伤害、时序及自定义模型保留。

0.7.3 随后按指定技能 ID 更新单剑、双刀、点刺和弓箭消耗，并分别迁移点刺时序、完美格挡窗口、硬直与左键反击参数。各迁移均保留原文件备份和一次性标记，具体字段与路径见 [0.7.3 版本说明](docs/release-0.7.3.md)。此前 3 点/秒的体力回复规则继续保留。

首次运行生成 `config/fsrpg/`，开发客户端实际读取 `run/client/config/fsrpg/`。JSON 使用 UTF-8；战斗时间为 **tick，20 tick = 1 秒**，模型动作时间为秒。

| 文件 | 内容 |
| --- | --- |
| `skill_trees.json` | 17 节点、学习成本、成长条件、基础训练、资质与缺席衰减；特殊突刺与双刀增益规则 |
| `archery.json` | 弓蓄力、箭速、耐久、撞击、弹道 / 瞄准镜阈值与四个分支的实际效果 |
| `skills.json` | 稳定技能 ID、一般动作时序、消耗、伤害、距离、标记、模型与动作引用 |
| `styles.json` | 档位、连招、取消、轻重格挡、兼容还击窗口与双刀控制模式 |
| `weapons.json` | 主副手物品 ID、双持要求、材质倍率，可加入其它 Mod 武器 |
| `combat.json` | 资源、恢复、拔收刀、硬直、闪避、通用防御及西洋剑索敌规则 |
| `collections.json` | 生物掉落与作物目录、提交需求、奖励和里程碑 |
| `quests.json` | 兼容教程任务、前置、目标、奖励与重复规则 |
| `models/*.fsvoxel` | 人体骨架与动作；新版使用 `legacy_rapier`、`legacy_dual_blade`、`legacy_bow` 及各自 `_fp` 文件，旧模型和长枪继续保留 |

`/fsrpg reload` 对整个配置集合校验后原子替换运行定义，失败保留上一份可用配置。弓 50 / 100 / 300 解锁阈值必须在 `skill_trees.json` 和 `archery.json` 中一致。未知字段、无效数值、重复 ID、循环前置和非法引用会被拒绝。技能树基础值是累计总值，学习只扣可用值；ID 应保持稳定。

K 窗口支持动作预览与一般技能数值修改，保存需要服务端管理员权限，并备份 `skills.json.bak`。特殊突刺的权威参数见上表，修改后通过 JSON 重载生效。外部编辑冲突必须先重载再保存。模型在 K 窗口重载；外部模型优先于 JAR 模板，自定义模型文件不被配置迁移覆盖。

世界数据分别位于 `<世界>/data/fsrpg/skill_trees.json`（玩家修行）、`archery.json`（弓技能资源）、`collections.json`（收集）、`quests.json`（旧任务）与 `resources.json`（战斗资源）。玩家数据按 UUID 隔离，移除的稳定 ID 保留在存档。**世界数据文件和 `config/fsrpg/` 的同名定义文件用途不同。**

收集提交保存扣除、奖励和交易回执，重复包不会重复发奖；旧任务页继续保留初次狩猎、技能训练和野外调查。旧任务领奖先保存已领状态再发奖励，仍有保存与交付之间异常终止导致未交付奖励丢失的原有限制。

## 服务端战斗与动画

服务器处理距离、方向、视线、有效帧、资源消耗与每次挥击的目标去重。前后摇不造成伤害；缓存输入在实际启动下一招时扣资源。一般技能冷却从接受施放时开始，特殊突刺从提交刺击时开始。死亡、收刀和强制状态会终止蓄力或攻击。

轻重格挡、弹刀、碰撞闪避和完美格挡反弹原版箭矢沿用现有规则。0.7.3 完美格挡默认窗口为 2 tick；成功后攻击者硬直 4 tick，怪物暂停 AI、移动和近战，结束后恢复。成功后的 4 tick 内，下一次被接受的左键攻击获得 1.5 倍普通攻击伤害；受击、闪避、收刀或换档会清除反击机会。PvP 继续遵守原版服务器规则。

旧武器第一 / 第三人称动作转换为现有 FSVOXEL 文件，继续使用官方玩家皮肤、盔甲和实际物品模型、资源包变换与附魔光效。已有 0.4 模型仍随包保留，外部自定义模型不会被替换。长枪保留动作文件和矩形操作，0.5.2 融合原动作与运行时两手 IK，沿用已有求解配置。0.7.0 额外接入生物原始动作，玩家武器动作继续沿用现有配置。动作与数值迁移来源、兼容规则见 [旧版技能迁移](docs/旧版技能迁移.md)。

`progressionTest` 覆盖 17 节点、真实训练、分支、成长和存档；`legacyMeleeTest` 覆盖蓄力取消、拨挡、提交冷却与双刀手位；`archeryTest` 覆盖两模式和弓分支；`configTest` 覆盖整集校验、字段迁移与阈值一致性；`legacyAssetTest` 检查旧动作转换资产。现有 `combatTest`、`collectionQuestTest`、`questTest`、物品 / 皮肤 / 姿态 / 长枪等测试继续保留。独立修行与近战证据见 `verification/progression-20261012/`，完整发行验收以最终构建和实机记录为准。

上一轮 0.5.1 执行长枪相关验证：`spearAimPoseTest` 检查刚性握点、骨长、正肘、限位与连续性，`spearSafetyTest` 比较 1930 个姿态的保守碰撞指标，`spearPitchContinuityTest` 检查 4094 个连续俯仰、转向与动作交接姿态。0.5.2 增加 `spearMovementContinuityTest`，覆盖原动作增益与相位、可行双手循环、同帧历史、时钟回退、READY 极值和招式交接，并运行 `poseLayersTest`、`presentationMotionTest` 及长枪核心专项；构建使用 `build -x check`，不重跑无关技能、任务与 HUD 项目。`tools/run-spear-solver-review.ps1` 在 DISPLAY5 的复制世界复核普通/纤细玩家的移动、瞄准、刺扫、收招、关节连续性和保守接触；最终专项、实机与残留接触记录见 [动作系统融合](docs/动作系统融合.md)。

`src/smoke` 与 `src/monitorAgent` 为开发源集，不进入发行包。录像按实际渲染帧采集并记录源时间戳，不能用编辑器预览代替游戏验收。旧 `verification/dual-remake-20261008/`、`weapons-r2/`、`rapier-r6/` 是对应旧版本证据，不作为本次长枪改善的证明。

核心包为 `combat`、`quest`、`progression`、`archery` 和 `config`；`RpgServer` 适配 Minecraft 事件、伤害、奖励与存档；`client` 显示服务器状态和发送输入意图；`network` 传输意图及快照。

0.5.4 的腋下枪姿、完整枪杆避碰和骨盆/转步说明见 [腋下枪姿与转步](docs/腋下枪姿与转步.md)。
