铁如筋腱，武器是身体和斗志的延伸，这个名字大概是这个意思。/n
我们重新设计了原版的械斗体验，加入了不同武器的动画和攻击技能，设定分支。/n
目前来看，我们主要制作了双剑和单剑的体验：/n
1.主手副手同时持剑，按下r拔刀进入战斗状态。左键左砍右键右砍，我们考虑了左右手应该是有序有限位的，左键优先左手砍，如果左手已经左砍，那么只能右手砍，如果两只手都已经左砍，此时无法左砍。右键同理。可以进入游戏左右砍一下看看，我们添加了攻击震动，还是很爽的。如果反复用同一只手挥砍，攻速会变慢。/n
2.主手持剑，按下r拔刀进入战斗状态，此时为西洋剑击剑模式。左键有四个固定顺序的动画。第三人称可以按e锁敌，此时角色朝向一定指向敌人。攻击四次后，敌人被取消1s ai（就是拔刀剑的处理方式）此时如果右键可以进行强化刺击，刺击得手后攻速增加。（刺击本身也算攻击，可以参与计数）（我们添加了计数器，可以在锁敌后看见敌人的名字，生命以及它收到的攻击数）/n
3.长矛或者枪，我们做了个毛。/n
计划未来是先做完完整的战斗体验，包括更好的动画，手感和格斗技能，比如：/n
双剑的定位是冲进一堆怪物里面乱砍，那么应该有攻速的机制和格挡机制，位移也要给足/n
西洋剑的设计是和强大怪物单挑，那么应该有良好的闪避机制，攻击时机控制（鼓励制造控制来创造攻击窗口，主动躲避攻击）（在考虑要不要做绝区零那种闪避后的奖励）/n
枪的定位是控制距离后攻击，应该会有快速拉开距离的闪避以及击退技能。但是我也在犹豫是不是可以融合原版体验，加入相对速度增伤以及骑马体验。/n
然后会加入成长机制，比如：/n
通过战斗学习一些技能，获得一些特性，增长一些数值，最后解锁一些动画，豪到一些怪物。/n
